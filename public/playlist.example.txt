【英文單字】🔤

// 字卡：同一個單元裡的「卡:」會集成一本，小朋友可以翻卡、聽發音、考考自己
//   卡: 字 | 說明 | 圖（emoji 或圖片） | 影片片段（網址 開始-結束）
// 欄位順序寫錯、少寫都沒關係，App 會看內容自己判斷
// 說明寫哪種語言就唸哪種：只寫中文只唸中文、只寫英文只唸英文
// 單元名稱裡有 ABC，就會照 A～Z 排好、標出開頭字母，上面多一排 A～Z 可以直接跳
// 一次產生一串數字卡：數字卡: 0～100 | 中文（或 英文），最多到 999
// 字卡本: 名稱 → 開一本新的字卡但不多分一層，同一區的好幾本直接排在同一個畫面
// 圖寫兩張的話，第一張是正面、第二張是背面，例如數字形狀卡：
//   卡: 3 | 3、3、蝴蝶3 | cards/shapes/3-q.webp | cards/shapes/3.webp
// 說明寫成「3、3、蝴蝶3」這種口訣格式，就照口訣唸；ABC 字母卡會自動唸「P、P、puh、puh、panda」
