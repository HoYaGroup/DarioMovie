# 我的學習影片 — 兒童專注觀影 PWA（Vue 3 + Vite 版）

給小朋友看學校教學影片用的網站。**只播放家長指定的影片，看不到 YouTube 的推薦、相關影片與結束畫面。**
影片分三層管理，也可以放學習網站；家長能設定每天看多久、多久休息一次，改錯了還能一步步復原。
可以「加入主畫面」變成 iPad 上的獨立 App。

技術：**Vue 3 + Vite**（純前端 SPA，無 SSR）+ YouTube IFrame Player API + `vite-plugin-pwa`。

> 這是原本 [Nuxt 4 版本](../DarioMovie) 的重寫版，功能完全相同，只是換成不依賴 Nuxt 特有 API 的一般 Vue 寫法，
> 兩個專案是各自獨立的 git repo，互不影響。

---

## 快速開始（本機開發）

```bash
npm install
npm run dev       # 開發，預設 http://localhost:5173
npm run dev:like-deploy   # 同上，但 public/cards/books/（不進 git 的書頁圖片）回 404，看部署後、還沒匯入素材包的樣子
npm run build      # 產出靜態網站到 dist/
npm run preview    # 預覽 build 出來的正式版（PWA 安裝/離線只有這個模式才會生效）
```

## 部署到 GitHub Pages

**不用自己手動建置。** 這個 repo 已經附上 `.github/workflows/deploy.yml`：

1. 把整個資料夾推到 GitHub 上一個新的 repo（`main` 分支）
2. 到 repo 的 **Settings → Pages**，Source 選 **GitHub Actions**
3. 之後每次 `git push` 到 `main`，GitHub Actions 都會自動 `npm run build` 並部署到 GitHub Pages

網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`（如果 repo 剛好叫 `<帳號>.github.io`，網址就是根網域）——
workflow 會自動判斷是哪一種、幫 Vite 帶對 base path，不用手動設定。

## 裝到小米電視（打包成 Android App）

網站本身已經支援用電視遙控器操作（方向鍵在片單/播放畫面移動、確定鍵選取、返回鍵回到片單），
不用另外裝 App 才能用——但直接開瀏覽器每次要打網址不方便，可以打包成一個可以側載安裝的 Android APK：

1. 網站照上面「部署到 GitHub Pages」的方式部署好，記下網址（例如 `https://你的帳號.github.io/DarioMovie/`）。
2. 到 [pwabuilder.com](https://www.pwabuilder.com/) 貼上這個網址，讓它掃描確認 PWA 條件都過關。
3. 選 **Android** → 產生 TWA（Trusted Web Activity）套件，下載簽名好的 `.apk`。
   **請把 PWABuilder 產生的簽名金鑰保存好**——以後要更新版本必須用同一把金鑰重新打包，換了金鑰電視會當成完全不同的 App，舊的要先移除。
4. 側載安裝到小米電視，兩種方式擇一：
   - **USB 隨身碟**：把 `.apk` 複製進隨身碟，插上電視，用電視內建的檔案管理員打開安裝（第一次要在電視設定裡開啟「允許安裝未知來源」）。
   - **ADB（免隨身碟）**：電視「設定 → 關於本機」連點版本號開發者選項，開啟「網路除錯」，然後在電腦上 `adb connect <電視IP>:5555 && adb install app.apk`。

**目前沒有另外設定網域驗證（Digital Asset Links）**，所以電視上開啟時螢幕最上方會有一條細細的網址列，
不影響操作，之後想要完全全螢幕，需要一個自己能控制根目錄的網域，把 PWABuilder 產生的 `assetlinks.json` 放到
`https://你的網域/.well-known/assetlinks.json` 下才能拿掉。

**電視版沒有家長設定頁**——遙控器沒辦法做長按、拖曳排序這些操作，所以電視上直接看不到齒輪設定入口。
電視也要有書單的話，把試算表連結用 `?sheet=` 帶給它（見下面「書單在 Google 試算表」最後的「電視版」）；之後家長改試算表，電視下次開啟會自動套用；
手機/電腦的一般瀏覽器開同一個網址，家長設定頁（長按齒輪、PIN、線上加影片等）完全不受影響、照常可用。

**電視上也沒辦法設定孩子的出生年度**（見下面「依孩子的年紀，只顯示適合他這一班的教材」）——這個設定存在各台裝置自己身上，
電視沒有設定頁，所以電視會把幼幼班到大班的教材都列出來。要讓電視也只顯示一班的話，目前沒有辦法。

## 兩個畫面：學習首頁、影片時間

小朋友的畫面分成兩個，不混在一起：

- **學習首頁**（一打開看到的）：「今日任務」加一排大分類圖示（數字、英文單字、我的書……），點一個進去才看那一區的分區、單元和字卡本，
  `← 返回` 回首頁。一次只出現一層標籤，首頁不會同時擺好幾排。只有一個大分類時不多這一層，字卡直接排在任務下面。
- **🎬 影片時間**：YouTube 影片和網站都在這裡，要家長輸入密碼才進得去——首頁右上角的 🎬（角上有小鎖頭）點了會跳出密碼鍵盤
  （跟家長設定同一組密碼，鍵盤上寫「要讓孩子看影片嗎？」）。小朋友按「返回」回學習首頁，要再看就要家長再輸入一次。
  裡面還是大分類 → 分區 → 單元，「接續播放」、沒網路的提示也在這裡。
- **怎麼分是依類型自動分**，試算表不用多寫任何欄位：字卡本＝學習、影片和網站＝影片時間。
  學校給的教學影片（放在像 `數字›影片` 這種分區）也在影片時間，不在學習首頁。
- 每日時間上限和強制休息兩個畫面共用：字卡也算螢幕時間（見 `CardDeck.vue`），用完兩邊都鎖住。
- **電視版**沒有密碼鍵盤、也沒有家長設定入口，所以 🎬 不上鎖，直接進影片時間（不然電視就完全沒東西看）。
- 返回鍵一次退一層（影片 → 影片時間 → 學習首頁）。
- 程式：`LearnHome.vue`（學習首頁）、`FunLibrary.vue`（影片時間）、`ShelfBrowser.vue`（兩邊共用的分區／單元／格子）、
  `composables/useShelf.ts`（`shelfOf()` 決定一項屬於學習還是影片時間）、`App.vue`（畫面切換和返回的 `trail`）。

## 分區、細分與片單

三層結構：**分區 → 細分（冊／單元） → 影片**，外面還包一層大分類（數字、英文單字、學習……）。

### 書單在 Google 試算表（專案裡沒有任何書單檔案）

整個學習庫——影片、網站、**字卡**——都放在家長自己的 Google 試算表。專案和 GitHub 上沒有任何書單，
所以學校給的教材不會公開；字卡有錯字、問句問錯、換影片，也都不用改程式、不用重新部署：
在手機或電腦改完存檔，iPad 下次開 App（或在家長設定按「立即同步」）就更新。

**第一次設定**（沒有試算表的話，先拿範本：家長設定的「學習單」面板有「下載範本」，檔案在 `public/template/booklist-template.xlsx`，
用 `node scripts/make-template.mjs` 產生；裡面有「說明」工作表和一個字卡、一個影片的範例工作表，只放自己寫的字卡和官方影片的連結。
想給其他家長一鍵複製：把範本匯成 Google 試算表後，把共用連結最後的 `/edit` 改成 `/copy`，點的人會得到一份自己的複本）


1. 做出試算表：照下面「試算表怎麼寫」新建一份；或把現成的 xlsx 變成 Google 試算表——
   - 電腦：Google 試算表 → 檔案 → 匯入 → 上傳 →「取代試算表」（試算表的網址不變）。
   - 手機（不用電腦）：把 xlsx 傳到 Google 雲端硬碟 → 點檔案用「試算表」開啟 → 選單的「儲存為 Google 試算表」，會得到一份新的試算表。
2. 試算表右上角「共用」→ 一般存取權改成「知道連結的任何人」、角色「檢視者」（不要關掉「檢視者可以下載」）→ 複製連結。
3. 在 iPad：家長設定 →「來源備份」→「學習單（Google 試算表）」貼上連結，按「儲存並同步」。
   也可以在 Safari 打開 `https://<你的網站>/?sheet=<剛複製的連結>`，連結會自己存起來（只有這台還沒設定過的時候才收，網址列也會清乾淨）。

專案裡**沒有任何書單檔案**：`.gitignore` 擋著 `/playlists/` 和 `/public/playlist*.txt`，免得有人把書單又 commit 進來。

#### 試算表怎麼寫

**一個工作表就是一個分區，沒有另外的「目錄」**：工作表的順序就是小朋友看到的順序（直接拖曳工作表分頁就能排），
隱藏的工作表不讀（暫停一整區的做法），名叫「說明」和「問句」的工作表不是分區（「說明」寫給人看，「問句」見下面）。
**分區自己的設定寫在那個工作表的「分區」那一列**，所有裝置一起同步；家長設定的「分區管理」頁改的只存在那一台，下次同步會被試算表蓋掉
（那一頁最上面有提醒，也有「開啟試算表」的按鈕）。
（舊的做法——另外做一個「目錄」工作表，列 大分類｜工作表｜分區｜圖示｜階段｜大分類階段——還讀得懂：有目錄的話，只讀它列出來的工作表、順序照目錄，
沒有「分區」那一列的工作表就用目錄的設定。新做的試算表不用目錄。）

第一列是欄位名稱（欄的順序可以調、用不到的欄可以刪），之後每一列用第一欄的「類型」說明是什麼：

| 類型 | 名稱 | 其他欄 |
|---|---|---|
| `分區` | 小朋友看到的分區名稱（空白就用工作表的名字） | 大分類（例如 `數字 🔢`，空白就跟上一個工作表一樣）、圖＝圖示、階段＝這一整區適合哪幾班。一個工作表寫一列就好，通常放最上面 |
| `單元` | 單元名稱（影片上方的小標題） | 階段：這個單元適合哪幾班 |
| `字卡本` | 字卡本的中文名（下面的「卡」都是這一本的） | 說明＝英文名稱（全英文模式顯示）、階段、問句（這一本每張卡正面問的那一句，見下面） |
| `卡` | 卡片上最大的字 | 說明（中文）、圖、句子1～N、問句、背面圖、影片片段、唸法、相反詞、放哪裡、聲音（見下面「字卡」） |
| `影片` | 標題（可以空白，會自動抓 YouTube 的片名） | 網址、階段 |
| `網站` | 標題 | 網址（在 App 內開啟，小朋友不會跳出去）、階段 |
| `設定` | 一整行設定：`任務: …`、`順序: 是`、`書頁: …`、`數字卡: 0～100` | 寫在它管的字卡本（或分區，還沒有字卡本的時候）下面 |
| `備註` | 給人看的，App 不讀 | |

同名的分區（像四個大分類都有的「影片」），工作表要取不一樣的名字（`數字›影片`、`英文單字›影片`），「分區」那一列的名稱再寫「影片」。

**階段寫在哪一列，就管那一層**：「分區」那一列管整個工作表，「單元」「字卡本」「影片」那一列管自己；底下沒寫的沿用上一層，都沒寫就每一班都顯示。
所以整個工作表同一班的只要在「分區」那一列寫一次，不一樣的再在那幾列各寫各的；不用另外的目錄，也不用每個工作表重複寫。

**卡片正面的問句**（每張卡正面問的那一句）：**每一句問句有一個名字**（東西、顏色、誰、哪裡……），字卡本和卡片的「問句」欄只選名字；
問句的**英文和中文寫在「問句」工作表的同一列**（問句｜英文｜中文），統一在那裡管，所以英文和中文不會對不起來。問哪一句，由近到遠：

1. 卡自己的「問句」欄（下拉選單選名字）：只有這一張卡。
2. 「字卡本」那一列的「問句」欄：這一本每張卡預設問這一句。匯入的書單，每一本現在用的是哪一句都已經填在這一格，看得到、改得了。
3. 都沒寫：照字卡本的名稱自動決定（名稱有「顏色」就問 What color is this?）。

- **改某一句的字**：到「問句」工作表改那一列的英文、中文，用到這一句的所有卡一起改（例如把「東西」改成 What is it?／這是什麼東西？）；
  整列留空或刪掉就用程式內建的。內建的問句只寫一種語言也可以，另一種語言用程式內建的那一句。
- **要新的問句**（像 What animal is this?／這是什麼動物？）：在「問句」工作表最下面加一列，名字自己取（例如 `動物`），**英文和中文都要寫**；
  之後字卡本、卡片的「問句」欄（下拉選單）就能選它。名字不能含 `|` 或括號，最多 30 個字；「問句」欄寫了工作表裡沒有的名字，家長設定會提醒是哪一列。
- 最後三列「數字」「識字」「注音」是數字卡、中文字卡、注音卡正面問的固定的話（它們不看「問句」欄），也在這個工作表改；這三個名字不能選給卡片。
- 相反詞（Is it big or small?）、數一數（Let's count!）的問句要帶入字，不能改。只管卡片正面問的那一句；「考考我」的題目（Where is the cat?）還是程式組的。
- 舊的欄位名稱還讀得懂：「問法」欄＝「問句」欄；「問句」工作表舊的標題（問法｜問句｜問句中文）也讀得懂。
  以前每張卡自己寫整句的「問句」「問句中文」兩欄已經不用了（有字的話會提醒）。

程式：`src/utils/questions.ts`（問句工作表的字，也記一份在裝置上，斷線也用得到）、`frontQuestion()`（`src/utils/cards.ts`）、卡片畫面的 `frontAsk()`。

- **類型空白、有網址**：當成影片（不是 YouTube 的網址當網站）。另外也認得舊的簡單寫法：用「單元」欄代替單元列。
- 要寫「階段」：幼幼班、小班、中班、大班，可以寫 `小班～中班`、`幼幼班、小班`，空白就是每一班都顯示（見「依孩子的年紀」）。
- 同一支 YouTube 影片可以出現在不同單元（學校教材常這樣），同一個單元貼兩次會被略過並提醒。
- 試算表裡一格的字不會被當成指令：換行會變空白，`設定` 只收 任務／順序／書頁／數字卡／階段 開頭的一行，不會有人在格子裡開出新的大分類。
- 數字的格子（卡片上的字是 `3`）不用特別設定，不會被 Google 當成數字吃掉；但**輸入日期樣子的字**（`3/4`）Google 會自動改成日期，要改回純文字。
- 看不懂的列，家長設定會指出是哪個工作表的第幾列。上限 200 個工作表、每個 6000 列。

**怎麼讀**（`src/utils/sheetSource.ts`、`src/utils/xlsx.ts`）：App 把整本試算表「下載成 Excel」
（`docs.google.com/spreadsheets/d/<id>/export?format=xlsx`，只讀、不用登入、不用 API 金鑰；回應有 `Access-Control-Allow-Origin`，瀏覽器可以直接讀），
一次拿到每個工作表的名字和每一格，轉成 `src/utils/playlist.ts` 看得懂的文字再解析——所以字卡、任務、階段、問法、放哪裡……的行為跟以前完全一樣，
在這台裝置上改的標題、字卡、看過的紀錄也都照舊。解壓縮用瀏覽器內建的 `DecompressionStream`（iPadOS 16.4 以上）。
不選 CSV（gviz）是因為它一次只給一個工作表，而且數字和文字混在同一欄時，少數那一種會被當成空白。

- 開 App 時背景讀一次，也可以按「立即從試算表同步」。讀到的內容留一份在這台裝置（Cache Storage），讀不到（沒網路、被改成不公開）就用上一次的，不會整批不見。
- 只讀不寫：不會改試算表，也不用登入 Google。**知道連結的人看得到內容**；連結只存在這台裝置（localStorage，備份檔有帶，所以備份請設密碼），
  **沒有寫進程式**，不然公開的 repo 裡就有連結了。
- 沒設定連結的新裝置是空的（「還沒有書單，請爸爸媽媽到家長設定貼上試算表網址」）。
- 把試算表改回「限制」、或在 App 按「移除這個連結」，這台已經讀進來的書單還在，只是不再更新。
- **檢查試算表有沒有寫錯**：`npm run check-sheet -- <試算表連結>`（或 `-- 書單.xlsx` 檢查下載下來的檔案）——跟 App 一樣讀一遍，指出看不懂的列，
  另外檢查同一個字在不同字卡本的句子要一樣、卡片寫的圖片音檔（`cards/…`）在 `public/` 找得到。
- 程式：`src/composables/useSheetSource.ts`（連結、上次的內容、`?sheet=`）、`src/composables/useLibrary.ts` 的 `syncFromPlaylist`。

**電視版**沒有家長設定頁，所以連結要用 `?sheet=` 給它：打包 TWA 的時候（PWABuilder）把「Start URL」設成
`https://<你的網站>/?sheet=<試算表連結>`，第一次開啟就會存起來。

### 素材：書頁圖片、叫聲放在自己的雲端硬碟

書頁照片和從書頁裁下來的圖（`public/cards/books/`，292 個檔案、約 9 MB）有版權，**不放在公開的 GitHub，也不放在公開的網站**
（已經 `git rm --cached` 並寫進 `.gitignore`；檔案還在你自己電腦的 `public/cards/books/`，要重裁就用 `scripts/crop-book.mjs`）。
它們改放在你自己的 Google 雲端硬碟，抓到每台 iPad 上，原樣存在那台裝置（IndexedDB，不縮圖不轉檔，書頁才不會糊），**之後沒網路也看得到、聽得到**。
兩種抓法擇一，都在 iPad 家長設定 →「照片素材」→「圖片和聲音」：

| | 做法一：素材包（zip） | 做法二：雲端硬碟資料夾同步（進階） |
|---|---|---|
| 要金鑰嗎 | 不用 | 要自己申請 Google API 金鑰（免費，只要做一次） |
| 雲端硬碟上放什麼 | 一個 zip | 一個資料夾，裡面的結構跟 zip 一樣 |
| 改了之後 | 重新打包、每台 iPad 重新匯入 | 改雲端硬碟，要用的時候在 iPad 按「立即同步」，才把有變的檔案下載下來（不會自己跑）；雲端硬碟上刪掉的，這台也跟著刪 |
| 程式連不連 Google | 不連（選檔靠 iPad「檔案」App） | 連 `googleapis.com`，只讀 |

**兩種放的結構一樣**：路徑就是試算表「圖」「背面圖」「聲音」欄寫的路徑（`cards/books/animals/pets.webp`），**試算表不用改**。

**做法一：素材包**

1. **打包**：`node scripts/pack-media.mjs`（預設打包 `cards/books` 和 `cards/sounds`，輸出 `private/素材包.zip`；
   `node scripts/pack-media.mjs 我的素材.zip cards/books cards/mine` 可以指定輸出檔和資料夾，路徑相對 `public/`）。
2. **放雲端**：把 zip 傳到自己的 Google 雲端硬碟（手機、電腦都行；不用共用，只有你自己的 iPad 要讀）。
3. **匯入**：iPad 家長設定 →「照片素材」→「圖片和聲音」→「選擇素材包」→ 在「檔案」App 裡打開雲端硬碟 → 點那個 zip。每台要用的 iPad 各匯入一次。

**做法二：雲端硬碟資料夾同步**

1. **放資料夾**：把素材包 zip 解壓縮，整個 `cards` 資料夾上傳到雲端硬碟的一個資料夾（例如「素材」）；以後要加圖，照同樣的路徑放進去。
2. **共用**：那個資料夾設成「知道連結的人都能檢視」（程式只讀；連結只存在你的 iPad，不會出現在 GitHub 或網站上，但**知道連結的人看得到裡面的檔案**，不要貼到別處）。
3. **同步**：iPad 家長設定 →「照片素材」→「圖片和聲音」→ 展開「做法二」，填資料夾網址和 Google API 金鑰（頁面裡有「怎麼拿 Google API 金鑰？」的步驟）→ 按「立即同步」。
   第一次要一個一個下載（幾百個檔案，按鈕上有進度）；之後只下載有變的。**只有按「立即同步」才會下載，開 App 時不會自己跑**（要用的時候再按，不會偷偷用掉網路和空間）。
4. 一個資料夾管三種東西：**子資料夾裡的圖片和聲音**是素材（路徑＝檔案在資料夾裡的位置）；**最上層的照片**（`apple.jpg`）是「換成家裡的照片」，用檔名對卡（見下面「跟其他裝置共用」）；
   **最上層的音檔**（`I'm hungry.m4a`）是爸媽的錄音，檔名就是那句話（見「用自己的聲音錄音」）。

- 沒抓到、網站上也沒有的圖：字卡上那一塊空白（不是破圖的小圖示），其他照常能用。
- **優先順序**（`src/utils/cards.ts` 的 `imageSrc`）：你自己拍的照片（「換成家裡的照片」）→ 素材（素材包或資料夾同步）→ 網站上的 `public/cards/`。聲音也一樣。
- **聲音也可以放雲端硬碟**：打包時帶上 `cards/sounds`（預設就有）。預設的 8 個叫聲是 Wikimedia 的免費授權音檔（CC0／CC BY，作者標在
  家長設定的「圖片與聲音來源」），放在 `public/cards/sounds/` 沒有版權問題，所以留在專案裡，其他家長不用做任何事也有叫聲；要換成自己錄的，蓋同一個路徑就好。
- 素材**不放進備份**（備份檔才不會多出幾十 MB）：換 iPad 或清掉 App 資料後，重新匯入同一個 zip、或按一次同步就回來。
- 檔案都當不可信的（兩種做法同一套檢查）：只收圖片（webp、jpg、png、gif、avif）和音檔（wav、mp3、m4a、aac），不收 SVG、HTML；路徑不能跳出資料夾（`../`）；
  圖片要真的打得開、音檔開頭要對得上副檔名；單檔上限圖 8 MB、音檔 10 MB，最多 3000 個檔案。沒收的會列出原因。
  資料夾同步另外：最多 300 個資料夾、8 層；名稱含 `/` 或 `\` 的檔案不收；捷徑、Google 文件略過；同一個路徑有兩個同名檔案取最新的。
- **資料夾同步怎麼判斷「有沒有變」**：記下每個檔案的 id 和 md5，一樣就不重新下載。雲端硬碟上已經沒有的，這台**從資料夾抓來的**也刪掉（匯入素材包的、自己拍的照片不動）；
  資料夾讀不完整（太多、太深）、或裡面一個素材都沒有的時候不刪，免得出一點狀況就把整批清掉。金鑰不對、額度用完、連不上這類整次都會碰到的問題，整次停下來、說清楚，這台的素材一個都不動。
- **別的家長有自己的書、自己的照片**：自己做素材包（或資料夾）就好，路徑跟自己試算表「圖」欄寫的一樣（`cards/mybook/p1.webp`）；iPad 的「檔案」App 也能把資料夾壓縮成 zip。
- **為什麼不是直接在試算表貼雲端硬碟的連結**：雲端硬碟「分享連結」轉成圖片網址的寫法是社群流傳的、Google 沒有正式文件，隨時可能失效；
  動物叫聲是程式解碼播放的，直連雲端硬碟多半會被瀏覽器的跨網域規則擋住；而且每個檔案都要各自取連結、貼進試算表，幾百張圖做不完。
  所以抓到這台裝置、照路徑對應，試算表不用改，離線也能用。
- 程式：`src/utils/media.ts`（存取、檢查、匯入）、`src/utils/zip.ts`（讀 zip，試算表的 xlsx 也用它）、`src/utils/driveSync.ts`（讀雲端硬碟資料夾、同步）、
  `src/components/MediaPack.vue`（面板）、`src/components/DriveFolder.vue`（資料夾同步的設定和結果）、`scripts/pack-media.mjs`（打包）。

### 公開的 repo 能放什麼

網站和 repo 是公開的，放上來就是「公開散布」。**讓使用者自己下載存到自己的雲端，不會讓公開散布變合法**：
私人使用的例外保護的是「自己重製、自己用」的人，不包括把檔案放到公開網站讓大家下載的人。

| 可以放 | 不要放 |
|---|---|
| 程式、自己寫的字卡文字和句子、自己拍的物品照片（沒有人臉） | 學校或出版社教材的掃描、書頁照片和從書頁裁下來的圖 |
| 授權允許的圖片和叫聲（CC0、CC BY 等，依授權標作者，見 `scripts/real-credits.json`） | 卡通角色的官方圖片、別人的 mp3／錄音檔、別人的歌詞和課文 |
| YouTube 影片的**連結**（App 用 YouTube 自己的內嵌播放器，影片還在 YouTube 上，影片擁有者也允許嵌入） | 不公開（unlisted）影片的連結：知道連結就能看，放到公開 repo 就等於公開了 |

不放的東西可以放在自己的雲端（Google 試算表、素材包、共用資料夾）或只存在 iPad 上（照片、錄音）；`.gitignore` 的 `/drive/`、`/Little Fox/`、`/private/`、`/playlists/`、`/public/cards/books/` 就是放這類檔案的地方。
書頁圖片改成素材包（上一節），不在公開的 repo 和網站上。
`public/cards/` 裡留著的是自己做的（abc、shapes、fruits、letters）和免費授權的（real、sounds，作者標在「圖片與聲音來源」）。
這不是法律意見：要公開推廣或收費的話，先找懂著作權的人看過。

### 字卡：把學過的數字、單字做成一本卡片

**這一節和下面幾節用文字寫法舉例**（`卡: apple | 蘋果 | 🍎` 這種一行一張卡）——那是試算表每一列轉成的文字，解析器讀的就是它。
在試算表裡一個欄位對應一個寫法：

| 文字寫法 | 試算表 |
|---|---|
| `# 數字 🔢` | 「分區」那一列的「大分類」 |
| `【認數字】💯` | 一個分區一個工作表；「分區」那一列的名稱、圖 |
| `《第 1 課》` | 類型「單元」那一列，名稱寫單元名稱 |
| `字卡本: 中文名 | English name` | 類型「字卡本」：名稱＝中文名，說明＝English name |
| `卡: apple | 蘋果 | 🍎 | Yum!` | 類型「卡」：名稱＝apple，說明＝蘋果，圖＝🍎，句子1＝Yum!（句子寫在「句子1、句子2…」，一格一句） |
| `影片網址 | 標題`、`site: 網址 | 標題` | 類型「影片」「網站」：網址＋名稱（標題） |
| `問:誰`、`對:small`、`放:廚房`、`聲:cards/sounds/cow.wav`、`唸:玻` | 欄「問句」「相反詞」「放哪裡」「聲音」「唸法」 |
| 卡的第二張圖、影片片段 | 欄「背面圖」、「影片片段」（`https://youtu.be/xxx 0:35-0:42`） |
| `階段: 小班～中班` | 欄「階段」（寫在哪一列就管哪一層，整個分區的寫在「分區」那一列） |
| `任務: …`、`順序: 是`、`書頁: …`、`數字卡: 0～100` | 類型「設定」，名稱寫那一整行 |

同一個單元（《》）或同一本字卡（`字卡本:`）裡的卡會集成一本字卡，跟影片排在一起：

```
【數一數】🍎

字卡本: 數一數 1～10
卡: 1 | 🍎
卡: 3 | 🐸 | https://youtu.be/xxxxxxxxxxx 0:35-0:42

【ABC】🔠

字卡本: 動物 ABC
卡: cat | 貓 | 🐱 | Meow! I am a cat.
卡: dog | 狗 | cards/dog.jpg | Woof, woof! I am a dog.
```

第一欄是卡片上最大的字，後面的欄位**看內容自動判斷**，順序寫錯、少寫都沒關係：

| 欄位 | 怎麼判斷 | 例子 |
|---|---|---|
| 句子 | 有英文、用 `.` `!` `?` 結尾的，翻面時接在單字後面唸；寫好幾欄就是好幾句，每次翻到輪下一句 | `Yum, delicious apple!`、`Give me the ball.` |
| 說明 | 不是圖、不是影片、不是句子的就是說明，英文中文可以寫在一起 | `貓`、`一支鉛筆 one pencil` |
| 圖 | emoji，或圖片網址、`public/` 底下的圖片路徑；寫兩張的話，第一張是正面、第二張是背面 | `🐱`、`cards/dog.jpg` |
| 影片片段 | 有 `youtu` 字樣，後面可以接「開始-結束」 | `https://youtu.be/xxx 0:35-0:42` |
| 這張卡的問句 | `問:` 開頭（問句的名字），只有跟字卡本預設不合的卡才需要寫（見下面「正面問的問題」） | `問:東西` |
| 相反詞的另一半 | `對:` 開頭，正面問 Is it big or small? | `對:small` |

小朋友端有兩種玩法，每一步都會用簡單的英文告訴小朋友現在要做什麼（卡片下面同時寫出英文和給爸媽看的中文）：

- **看卡片**：換到一張新卡就問「What is this?」（數字卡問「What number is this?」），先猜再點一下翻面。
  翻面時中文、英文一起唸，再接一句簡單的英文：
  - 單字卡：「蘋果。Apple. Yum, delicious apple!」——句子沒寫的話會說「I see a cat.」
  - 一張卡可以寫好幾句，每次翻到這張卡就換下一句（第一次從隨便一句開始），同一本卡每天聽起來都不太一樣：
    `卡: cat | 貓 | 🐱 | Meow! I am a cat. | Shh! The cat is sleeping. | Pet the cat gently.`
    學習庫裡每個英文單字都寫了三句，句型錯開（叫聲、It can／has、問答、Let's…、打招呼），
    同一個字在不同字卡本用同一組句子
  - 數字卡：「One. 一支鉛筆. One pencil.」（說明寫「中文 英文」），只有數字的卡說「Thirty-one. 三十一.」

  有影片片段的卡多一顆「看影片」，只播老師教這個字的那幾秒，播完自動關掉。
- **跟我說／做動作**：換小朋友自己開口、動一動，不是只有點。每一本字卡上面多一顆按鈕，一輪最多八張：
  - **跟我說**（一般字卡本，像生活用語、卡通常說的話）：App 說「Let's play!」→ 說一句（`I'm hungry`）→「Your turn!」，
    圖卡下面的圓圈跑一圈（句子越長跑越久）就是他說的時間 → 說完 App 回應「You said it!」「Great talking!」，再換下一張
  - **做動作**（動作、口令、習慣、作息、守則、洗手步驟、地震這類，名稱會自動判斷）：App 說「Stand up!」→「Do it!」→
    他真的站起來、拍手、洗手 → 做完 App 回應「You did it!」
  - **不做語音辨識**：幼兒的口音、iPad 主畫面 App 都容易判錯，判錯會讓他挫折。目標是讓他開口、動起來，爸媽在旁邊聽、看就好。
    圓圈跑完（或小朋友點圓圈）一律鼓勵；「再聽一次」重聽、「下一張」跳過（跳過的不算）
  - 卡很多的字卡本（ABC 26 張）每一輪接著上一輪玩；卡不多的整本照順序玩（洗手步驟要照順序）。中文／中英／English 都照上面的語言切換
- **考考我**：「Let's play a game!」之後出題，從三張卡裡點出對的。一次答對拿一顆星（星星記在這台裝置上）；
  答錯的字會在這一輪最後再考一次。題目輪流換三種問法，讓小朋友聽懂不同的說法：
  「Where is the cat?」「Can you find the cat?」「Can you touch the cat?」——
  數字說「Can you find number seven?」，顏色說「Where is red?」，複數說「Where are the glasses?」。
  題目只用聽的、不寫出來（寫了就等於給答案），想再聽一次就按上面的 🔊。
  答對說一句讚美再把名字說一遍（`Yes!`／`You got it!`／`Great listening!`……輪流換，不會連著兩次一樣；Cat. 貓），
  點錯不說 No，說「Hmm, not that one.／Oops!／Almost!」，告訴他點的是什麼，再把題目問一次：
  「Oops! This is a horse. Listen again. …… Where is the frog?」，
  「Listen again.」後面會停將近一秒，題目才不會跟前一句黏在一起。
  家長設定頁可以填**孩子的小名**，答對、做完動作時每三次叫一次（`Great job, Dario!`；點錯不叫名字）；只存在這台裝置上。
  點錯的那張會貼上「🔊 horse 馬」，再點一次只唸它的名字（This is a horse.），不再扣分，
  小朋友可以自己比較。玩完一輪說「Great job! You got five stars!」。
  卡片是一句話的（生活用語、卡通常說的話、見面問候）或動物叫聲（這是誰的聲音），題目改問「Which picture says, I'm hungry?」，點錯說「This picture says, I can do it.」。
  英文會自動分 a／an（an apple、a unicorn、an x-ray fish、a xylophone），複數說 These are（glasses、fries）；
  數字和顏色不加 a——顏色卡的說明寫成「紅色」這種「…色」結尾，就會說 This is red。
  數字形狀卡兩種題目混著出：看圖選數字（What number is this?），以及聽數字從形狀圖裡找出拐杖。

**中文／中英／English 切換**：字卡畫面上方可以切換，**預設 English**，選了之後記在這台裝置上，每一本字卡都照這個設定。

- **English**：全英文，不摻中文——唸的、卡片上寫的、按鈕都是英文（Apple. Yum, delicious apple!／One. Like a pencil.／Eleven. Eleven apples.）。
  英文句子只有這個模式會唸。
  背面原本放「印著中文的原卡」的（ABC 圖卡、數字形狀卡），會改放正面那張圖；
  字卡本名稱顯示英文名：名稱本來就有英文的（農場動物 Farm）只留英文，沒有的在片單寫 `字卡本: 數字像什麼 1～10 | Number Shapes 1-10`
  （英文名稱不算進識別碼，加上去星星不會歸零）
- **中文**：全中文，不摻英文——翻面唸「蘋果」「一，像一支鉛筆」「十一，十一隻貓」；
  題目是「蘋果在哪裡？」「你找得到蘋果嗎？」「哪一個是蘋果？」，數數前說「我們來數貓！一隻一隻點。」、用「一、二、三」數，數完問「有幾隻貓？」，
  回饋說「對！」「哎呀！這是馬。再聽一次。」（讚美、提醒都有好幾句輪流換）；ABC 卡的 Aa 標籤和印著英文字母的原卡先藏起來（上面 A～Z 那排是拿來跳頁的，留著）
- **中英**：中文說明＋英文單字，專心把中文和英文對起來，不唸英文句子：
  翻面「蘋果，apple」「一，one。像一支鉛筆，like a pencil」「十一，eleven。十一隻貓，eleven cats」；
  指令用中文（這是什麼？／我們來數魚！一條一條點。），數數用英文 one、two、three；
  考考我「找找看… apple」「哪一個是… seven」「apple… 在哪裡？」，點錯說「哎呀！這是馬，horse。再聽一次。」

**數字卡**：數字不再分成中文版、英文版，一張卡中文、英文都有（照上面的切換決定唸哪種）。

- **數一數**：數字卡（1～20）放 emoji 的話，正面會畫出那麼多個東西，「Let's count! Touch the apples.」
  小朋友一個一個點，App 用英文跟著數 one、two、three……；數完問「How many apples are there?」，
  三個數字選一個，選對了翻面說「Eleven. 十一顆蘋果. Eleven apples.」。
  還沒答對之前點卡片不會翻面，而是再說一次現在要做什麼（還在數就說 Touch the apples，數完了就再問 How many）。
  超過 10 的前 10 個排成兩排，看得出 13 是 10 再加 3。
  會說「apples」「十一顆蘋果」的 emoji 列在 `src/utils/cards.ts` 的 `COUNT_NOUNS`（常見的動物、水果都有，
  量詞也照中文說：兩隻狗、十二條魚），表上沒有的 emoji 一樣可以數，只是會說「Touch them」。
- **認數字**：數字卡沒放 emoji，正面就直接顯示數字，讓小朋友認數字的樣子（`卡: 13`）。
- **數字也能接一句英文**：寫在最後、用 `.` `!` `?` 結尾，翻面時接在後面唸，背面也寫出來：
  `卡: 2 | 我有兩隻眼睛 | I have two eyes.` 會說「Two. 我有兩隻眼睛. I have two eyes.」；
  `卡: 6 | Two, four, six!` 拿來做兩個兩個數、十個十個數的口訣。
- **上面一排數字**：數字是一天教一點，整本都是數字卡的話，上面會有一排數字可以直接跳到今天要教的那個；
  像 0～100 這麼多張，就變成每十個一格（0、10、20……100）。

**一次產生一串數字卡**：`數字卡: 0～100` 會產生 0～100 的數字卡（31 唸 Thirty-one. 三十一.）。
最多到 999（101 一百零一、200 兩百、125 one hundred twenty-five）。
數字題的考考我會挑容易搞混的數字當選項：31 配 13（左右顛倒）或 30、41（差一點點）。

**學習庫的難易度**：每一區裡的字卡本都照「簡單 → 有一點難」排。

- 數字：數字像什麼 1～10 → 認數字 11～20 → 兩個兩個數 → 十個十個數 → 0～100；
  數一數從 1～5 開始，再到 1～10（水果動物、海洋、交通工具）、11～20；最後是「數字在身邊」（A spider has eight legs.）。
  交通工具那本中文順便學量詞：一架飛機、三列火車、四輛公車、九艘帆船
  時間：四季 → 一天的時間（早上、中午、下午……）→ 星期 → 時鐘 整點 → 時鐘 半點 → 月份
- 英文單字分成三級：
  - **第 1 級**：家人、農場動物、寵物、顏色、身體、身體 2、吃吃喝喝、早餐、點心、玩具、水果、好習慣、禮貌小天使、上課口令
    （每天都看得到，句子最短）
  - **第 2 級**：形狀、立體形狀、衣服、教室裡、蔬菜、海洋動物、昆蟲、天氣、海邊、家裡、家裡的房間、廚房餐桌、交通工具、
    森林動物、相反詞 1～4、安全小幫手、小心過馬路、見面問候、動物園、樂器、球類、遊樂園、節慶、童話角色、太空、鳥類
  - **第 3 級**：心情、動作 1～2、運動、職業 1～2、工具箱、地方 1～2、押韻 1～2
    （摸不到的字，句子用 I am…、Let's…；押韻是學拼音前的暖身，字尾一樣的字排在一起）
  - **生活用語**（不是單字，是整句話）：吃飯、請人幫忙、出門、晴天雨天、玩遊戲、朋友之間、睡前、生病了、我的感覺、回答、
    在學校、買東西、問問題（13 本），一本一個情境，卡片的圖是兩三個 emoji 組成的情境（🤤🍔 肚子餓、🧒🙏👩 請媽媽幫忙），
    每張卡的三句都是這個情境裡自己會說的話，而且對得上圖（🤤🍔 → I'm hungry. I want a hamburger! ／ Mom, I'm hungry. Can I have a hamburger?）
- 中文：注音符號 ㄅ～ㄦ → 注音拼拼看（ㄇㄠ 貓）；國字從一～十、大小上下、家人、動作 1、量詞 1、前後裡外東西、顏色開始，
  大班再認象形字 1～5、學校、天空和大海、花草樹林、四季早晚、動作 2、量詞 2、相反字、數目
- **認識世界**不照單字難度分，照「認識什麼」分，幼兒園課綱的六大領域都放一點：
  - **大自然**：植物、動物寶寶（puppy、kitten、calf）、動物住哪裡（nest、web、pond）、恐龍、地形、科學小幫手、環保好習慣
  - **我自己**：五感（see、hear、smell……）、冷靜下來（深呼吸、數到十、找大人幫忙）、一天作息（從起床到睡覺）、洗手步驟、
    健康小習慣、看醫生、不舒服（fever、cough）、安全守則、地震怎麼辦（趴下、掩護、穩住）
  - **一起生活**：好朋友（分享、輪流、排隊）、台灣小吃（珍珠奶茶、便當、關東煮）、美勞時間（蠟筆、水彩筆、顏料）、
    親戚朋友（uncle、aunt、cousin）、超市購物
  - **世界**：台灣好地方（Taipei 101、日月潭）、世界各國 1～2，每個國家怎麼說 hello（Konnichiwa! Hello from Japan.），圖是國旗、七大洲

**動作、心情這種字**：單元名稱裡有「動作」「心情」（或 Actions、Feelings），問的時候就不加 the——
「Where is happy?」「Can you find run?」，點錯說「This is sad.」，跟顏色一樣。

洗手步驟、健康小習慣、環保好習慣、安全守則、地震怎麼辦、世界各國、台灣好地方、七大洲，生活用語（吃飯怎麼說、出門怎麼說……），
和卡通角色（波力、汪汪隊、玩具總動員）的單元與他們常說的話也一樣

**ABC 字母卡**：單元名稱裡有 `ABC`（半形、全形都可以），這本就會變成字母卡：

- 自動照 A～Z 排好，同一個字母可以放好幾張；新加的卡寫在哪裡都行，會自己排到對的字母去
- 卡片左上角標出開頭字母（`Pp`），背面把單字的開頭字母上色
- 上面多一排 A～Z，點字母直接跳過去；沒有卡的字母會淡掉

```
字卡本: 動物 ABC
卡: ant | 螞蟻 | 🐜 | The ant is small.
卡: alligator | 鱷魚 | 🐊 | Snap, snap! I am an alligator.
卡: bear | 熊 | 🐻 | The bear is big.
```

**ABC 形狀字母**（動物篇、美味食物篇、生活用品篇）：字母本身就是那個東西（A 是一隻鱷魚、B 是一隻熊），
圖放在 `public/cards/letters/`（`animals/`、`food/`、`things/`），一張卡一張圖：

```
字卡本: 動物篇 ABC
卡: alligator | 鱷魚 | cards/letters/animals/alligator.webp | Snap, snap! I am an alligator.
```

**數字形狀卡**（鉛筆1、鴨子2……）放在 `public/cards/shapes/`，每個數字兩張圖：
`3-q.webp` 是正面（只有形狀，數字用「?」貼紙蓋住），`3.webp` 是背面（完整的卡）：

```
字卡本: 數字像什麼 1～10
卡: 3 | 像一隻蝴蝶 like a butterfly | cards/shapes/3-q.webp | cards/shapes/3.webp
```

**識字卡（中文字、注音）**：第一欄是中文字或注音符號的卡，正面只寫那個字（不放圖，因為要認的就是字本身），
翻面才有圖和說明，一律唸中文，不管上面選哪個語言（那一本的語言切換會自動收起來）：

```
字卡本: 注音 1 ㄅㄆㄇㄈ ㄉㄊㄋㄌ
卡: ㄅ | 唸:玻 | 爸爸 | 👨
卡: ㄆ | 唸:坡 | 蘋果 | 🍎

字卡本: 象形字 1 日月山水火木土田
卡: 日 | 太陽、生日 | ☀️
```

- 正面問「這個注音怎麼唸？」「這個字怎麼唸？」，翻面唸「玻。爸爸。」「日。太陽、生日。」
- `唸:` 是語音要唸的字：注音符號單獨一個，語音引擎不一定唸得準，所以寫一個同音字代替（ㄅ 唸「玻」＝ㄅㄛ）。
  中文字的話不用寫，直接唸卡片上的字。**各裝置的語音不一樣，新加的注音建議先聽一遍**
- 考考我問「找找看……（停一下）玻」，答錯說「這是……坡」，選項就是那個符號或字
- 字卡本封面也露出符號，不是圖

唸單字用的是瀏覽器內建語音，不用錄音檔。電視上如果沒有語音，考考我會改成把題目寫出來。

**用自己的聲音錄音**（家長設定 →「用自己的聲音錄音」）：合成語音聽起來像機器，所以每一句都可以換成爸媽自己的聲音。

1. 選一本字卡（或「⭐ App 說的話」：Your turn!、Great job!、Let's play! 這些 App 自己說的話，還有孩子的小名）
2. 一句一句按「● 錄音」說話，說完按「■ 停止」，馬上放一次給你聽，不滿意按「重錄」
3. 之後小朋友聽到那句話，放的就是你的聲音；**沒錄的句子還是用合成語音**，不用一次錄完，想到再錄

- **依「那一句話」記，不是依哪張卡**：`I'm hungry` 錄一次，出現在哪一本字卡、翻面、跟我說、考考我答對說名字，都用你錄的。
  比對時不分大小寫、不管標點（`Stand up!` 和 `stand up` 是同一句），英文、中文分開記
- 預設只錄每張卡的詞句；勾「連例句一起錄」（每張卡三句）、「連中文一起錄」可以錄更多。「只看還沒錄的」方便接著錄
- **匯入現成的音檔**（mp3、m4a、wav）：手機錄音程式錄的、請老師錄的，不用在這裡重錄。
  - 每一句旁邊的 📁：選一個檔案，取代這一句
  - 最上面的「📁 批次匯入音檔」：一次選很多個，**檔名就是那句話**（`I'm hungry.mp3`、`Stand up.m4a`、`我聽不懂.mp3`），
    不分大小寫、不管標點，系統重複下載加的 `(1)` 會忽略；字卡的詞句、例句、中文、App 說的話都對得到，不用先選哪一本。
    對不到句子的、解不開的檔案會一個一個列出來
  - 一個檔對一句話（檔名對得上），**長度不限**，一段兒歌、一小段故事都可以；只擋超過 30 MB 的檔——播放時整段要解碼進記憶體，
    幾十分鐘的檔在 iPad 上會很吃力。麥克風最長連續錄 5 分鐘（怕忘了按停止）。ogg 在 Safari 解不開
  - 檔案是**複製**進這台裝置的資料庫，你電腦上的原檔不會動，匯入之後也不需要它；跟錄的音一樣不會上傳、不會跟著網站部署出去
- **存到雲端硬碟、給其他裝置用**（做法跟照片一樣）：最上面的「📤 全部存到共用資料夾」把每一句錄音做成一個檔案交給 iPad 的分享選單，選「雲端硬碟」再選共用資料夾。
  **檔名就是那句話**（`I'm hungry.m4a`、`我餓了.m4a`；不能用的符號換成底線，音檔原樣、不重新編碼）。
  - 另一台：用「📁 批次匯入音檔」在「檔案」App 選那個資料夾裡的檔案；或在「照片素材」設好資料夾同步（錄音放資料夾**最上層**），按「立即同步」就自己下載
  - 同步時：這台已經有大小一樣的（多半是自己存上去的）不再抓；這台自己錄的比資料夾裡的新，不蓋掉；錄音**只加進來、不刪**——資料夾裡沒有，不會刪這台的錄音
  - 句子太長、檔名被截短（80 個字）的，用檔名開頭去對，只有一句符合才算；整個學習庫的每一句（5800 多句）取檔名再對回來，測過都對得上（`src/utils/voiceLines.ts` 的 `lineOfFileName`）
- 錄音前後的靜音會自動剪掉（記下有聲音的那一段，播放時跳過），不用練習到剛剛好
- 存在這台裝置的 IndexedDB，**不會自己上傳、不會寫進片單、不會跟著公開網站出去，每台裝置各自錄**（換一台 iPad：用上面的「存到共用資料夾」帶過去，或用備份還原）；
  已經安裝成 App 的通常不會被瀏覽器清掉，沒安裝的話瀏覽器空間不夠時可能清掉，錄音比較多的話建議安裝成主畫面 App
- 錄音要 https 網址（GitHub Pages 是）或 localhost，第一次按錄音瀏覽器會問麥克風權限；Chrome 錄 webm、iPad 錄 mp4，各用各的
- 放不出來的錄音（解不開、瀏覽器不支援）會自動退回合成語音，不會整串卡住
- 有數字的句子（You got three stars!）每次不一樣，沒辦法預先錄，仍然是合成語音

程式：錄音存取在 `src/utils/recordings.ts`，`src/utils/speech.ts` 的 `speak` 每唸一段先查有沒有錄過，錄音介面是 `src/components/VoiceStudio.vue`，
分享出去、匯入的檔名規則在 `src/utils/clipFiles.ts`（雲端硬碟同步也用同一套）、`src/utils/voiceLines.ts`，
App 自己說的固定句子集中在 `src/utils/cheers.ts` 的 `PROMPTS`（新增 App 說的話請加在那裡，錄音清單才會列出來）。
自己拍的照片放進 `public/cards/`，片單裡寫 `cards/檔名.jpg` 就好——不過網站是公開的，
**不要放課本掃描圖，也不要放拍得到小朋友的照片**。

### 家裡的照片：用自己拍的東西取代 emoji 和網路照片

不用電腦、不用重新部署，**直接在 iPad 上**換。入口：**長按右上角齒輪 → 輸入家長密碼 → 「📷 照片」分頁**。

- **字卡**：在「照片素材」分頁的「換成家裡的照片」選一本字卡本，每張卡一格，**按一下卡片**就拍照或從相簿選（iPad 會問要現拍還是選相簿）；換好的打勾，旁邊有「還原」退回原本的圖
  （emoji 或 `cards/` 的照片）。數字卡是用 emoji 畫出幾個讓孩子數，不能換成照片。
  另一個入口：「片單 › 目前片單」打開字卡本、點一張卡，也有「📷 拍照或選照片」。
- **放哪裡的地點照片**（廚房、浴室、臥室、門口）：同一頁往下，直接換成自己家的。
- 「換成家裡的照片」最下面列出換過哪些卡，可以一張一張還原，或全部還原。
- 照片**另外存**，不改片單的字：片單同步、字卡改字都不會蓋掉它。**依卡上的字對應**：換了 apple，所有字是 apple 的卡（不分字卡本、大小寫）一起換；
  卡上的字改掉，那張照片就對不到卡了（面板會標紅色、可以刪）。
- 存進去之前一律**重畫一次、輸出 JPEG**：縮到最長邊 720px（約 50～150KB），拍照時的 EXIF（位置、時間、手機型號）全部丟掉。
  **iPhone 的 HEIC 也在這裡轉成 JPEG**，所以存起來、分享出去的都是每台裝置都打得開的 jpg。SVG、不是圖片的檔、打不開的檔都會擋下來。

**照片只存在這台裝置**（IndexedDB，跟錄音一樣）：不會自己上傳、不會寫進片單、不會跟著公開網站出去，換一台 iPad 不會自己跟過去。
要在幾台裝置之間共用，用「共用資料夾」（下一段）；要防壞掉，做備份（再下一節）。

#### 跟其他裝置共用：共用資料夾（雲端硬碟）

基本做法**不連任何雲端**，沒有 API 金鑰、不用登入 Google，GitHub 上也沒有任何設定：上傳靠 iPad 的分享選單，匯入靠「檔案」App 選檔
（想自動下載，才用後面的「自動同步」，那是進階功能，在「圖片和聲音」的「做法二」）。**檔名就是對應，不用另外記錄**：

| 檔名 | 換掉哪張圖 |
|---|---|
| `apple.jpg` | 所有字是 apple 的卡 |
| `place-kitchen.jpg` | 放哪裡的廚房照片（跟 `cards/real/place-kitchen.webp` 同名） |

- **只用「存出去」和「匯入」的話，資料夾不用在 App 裡設定**：App 不會連 Drive，是存的時候在分享選單選資料夾、匯入時在「檔案」App 選資料夾。
  要「填了網址就自動下載」，請看下面的「自動同步」（需要 Google API 金鑰，設定在「圖片和聲音」的「做法二」）。
- **存出去**：換好照片後按「📤 全部存到共用資料夾」（「照片素材」分頁；單張的在字卡編輯器裡）。檔名**程式自己取好**（`apple.jpg`），
  iPad 叫出分享選單，選「雲端硬碟」再選資料夾就好，**不用改檔名**。檔名裡不能用的符號（`/ \ : * ? " < > |`）會換成底線。
  這一步要你選資料夾，因為自動上傳得登入 Google，我們不做；電腦版或不能分享的瀏覽器會改成下載檔案，再自己移進資料夾。
- **匯入**：另一台按「📥 從資料夾匯入照片」，在「檔案」App 裡打開雲端硬碟那個資料夾，全選照片。副檔名、大小寫、重複檔名後面的「 (1)」都不計較；
  同一個名字有好幾個檔取最新的；對不到卡的檔名、不是照片的檔會列在報告裡。一次最多 400 個。
- 匯入的每一張都照一般照片**重新處理**（縮小、轉 JPEG、去位置資訊、擋掉不是圖片的），不直接相信資料夾裡的檔案。
  資料夾裡如果是原始 HEIC，只有 Safari（iPhone、iPad、Mac）打得開，其他瀏覽器會在報告裡說「HEIC 打不開」；從 App 分享出去的一律是 JPEG，不會有這個問題。
- **知道資料夾網址的人都看得到裡面的照片**，請不要放拍得到小朋友的照片。資料夾網址和金鑰不要寫進 repo（repo 是公開的）。

#### 資料夾同步：雲端硬碟資料夾（進階，選填，按了才同步）

設定在家長設定 →「照片素材」→「圖片和聲音」→「做法二」（跟素材共用同一個資料夾網址和金鑰，做法見上面的「素材」）。填好**資料夾網址**和 **Google API 金鑰**，按「🔄 立即同步」，這台就把資料夾裡的東西下載下來，不用一個一個手動匯入：
**最上層的照片**換成家裡的照片（下面這幾點），**最上層的音檔**存成爸媽的錄音，**子資料夾裡的圖片和聲音**存成素材。
**只有按了才會下載，開 App 時不會自己跑**（試算表書單才是開 App 時讀一次）。

- **為什麼要金鑰**：網頁沒辦法「列出」別人資料夾裡有哪些檔案，Google 只開放給帶 API 金鑰的 Drive API。金鑰免費、由每位家長自己在 Google Cloud 建
  （頁面裡有「怎麼拿 Google API 金鑰？」的步驟：建專案 → 啟用 Google Drive API → 建立 API 金鑰 → 建議限制成「只能用 Drive API、只能從這個網站用」）。
- **資料夾要設成「知道連結的人都能檢視」**。只讀：只做「列出」和「下載」，不上傳、不改、不刪；只連 `googleapis.com`；不帶 cookie、不用任何登入身分。
- **網址和金鑰只存在這台裝置**（localStorage），**不進備份、不進 GitHub**；金鑰不會出現在任何錯誤訊息裡。
- 最上層照片的檔名規則同上（`apple.jpg`、`place-kitchen.jpg`）；最上層一次最多 400 個檔案。抓下來的每張都照一般照片**重新處理**（縮小、轉 JPEG、去位置資訊、擋掉不是圖片的），不直接相信資料夾裡的檔案。
- **只抓有變的**：記下每個檔案的 id 和 md5，沒變就不重新下載；這台自己拍的照片如果比資料夾裡的檔案新，不會被蓋掉。
- 失敗會講原因（金鑰不對、沒啟用 Drive API、金鑰限制了網站、找不到資料夾、額度用完、連不上），結果顯示在「上次同步」；整次都會碰到的錯誤停下來，單一檔案壞掉只記在報告裡。
- 程式在 `src/utils/driveSync.ts`（Drive 讀取、同步）、`src/composables/useDriveSync.ts`（畫面狀態）和 `src/components/DriveFolder.vue`（畫面）。

### 備份與還原：iPad 壞了也不怕

「來源備份 › 備份與還原」把**照片、錄音、在這台裝置上改的東西**包成一個 `.kidtube` 檔，由你自己存到「檔案」App 或 Google 雲端硬碟。
程式本身**不連任何雲端**：沒有 Google 帳號、API 金鑰，GitHub 上也沒有任何設定；用哪個 Google 帳號、存哪個資料夾，都在你自己裝置的雲端硬碟 App 裡決定。

- **備份**：（選填）設備份密碼 → 建立備份檔 → 按「存到檔案／雲端硬碟」（iPad 的分享選單）或「下載檔案」。
  做好後程式會自己打開驗證一次，打不開就不會讓你以為有備份。
- **還原**：換新 iPad 或這台被清空之後，到同一個地方「選擇備份檔」。會先檢查檔案、顯示裡面有什麼，按「還原到這台裝置」才會動到資料，完成後自動重新載入。
  照片、錄音是「加進去」（同一張、同一句以備份為準），設定換成備份裡的。
- **備份裡有**：照片、錄音，以及片單（含在這台加的影片）、Google 試算表片單的連結、在這台改過的字卡／標題／網址／班級、孩子的年紀和小名、字卡星星、任務貼紙、觀看時間設定、外觀。
  **沒有**家長密碼、觀看紀錄、休息倒數——備份檔會放在雲端，不該帶著能進家長設定的鑰匙，還原後請重設密碼。
- **提醒**：有照片或錄音是上次備份之後才新增的，家長設定每一頁上面都會出現「有 N 個還沒備份」，備份完就消失。

安全：
- **備份密碼**用 AES-256-GCM 加密整個檔案（密碼經 PBKDF2-SHA256 25 萬次變成金鑰），檔案被改過一個位元組就打不開。
  **忘記密碼就永遠打不開，沒有後門。** 沒設密碼的檔案誰拿到都看得到家裡的照片和孩子的聲音，只放在自己的雲端硬碟。
- 還原時把檔案當不可信的：設定只收白名單裡的項目（`utils/backup.ts` 的 `BACKUP_SETTING_KEYS`）；照片、錄音的格式、大小、數量都要對得上，
  照片要真的打得開，任何一處不對就**整份拒絕**，不會收一半。只還原自己做的備份檔。
- 備份檔格式見 `src/utils/backup.ts` 開頭：照片、錄音是原樣的位元組（不轉 base64），幾十 MB 也不會吃光記憶體。
- 照片存取在 `src/utils/photos.ts`（`cardsOf`／`imageSrc` 查到換過的就用照片），共用資料夾的命名、分享、匯入在 `src/utils/photoFiles.ts`，
  介面是 `PhotoStudio.vue`（「照片素材」分頁）、`PhotoTile.vue`（一格一張卡）、`PhotoButton.vue`（字卡編輯器裡的一排按鈕）、`BackupStudio.vue`，換照片的動作共用 `composables/usePhotoSlot.ts`。

### 生活任務：認識一個東西，再到家裡找找看

字卡、考考我都是在螢幕裡玩。「任務」是**走出螢幕**：App 只負責出題和收尾，找東西的動作在家裡。
有寫 `任務:` 的字卡本，上面多一顆 🔎「任務」，流程是三步：

1. **認識**：看一張卡（用真實照片最好）、聽它的名字和一句話（`Bus. The bus is big.`）
2. **去找**：App 說任務（`Find more vehicles at home!`／「家裡找找看，還有哪些交通工具？」），小朋友離開螢幕去找，
   **找到一個就回來按一下「我找到了」**，App 把數字唸給他聽（One! Two! Three!）。按完要停 1.8 秒才能再按，
   不然連點三下什麼都沒找就完成了。不驗證他是不是真的找到了（跟「書上找」一樣），目標是動起來、跟爸媽一起看家裡的東西。
   這一步畫面不動，**不算進每天的觀看時間**
3. **貼紙**：找夠了，貼一張貼紙、拿一顆星星，畫面停在「關掉螢幕，去玩吧！」，不會自己接下一題

**首頁最上面的「今日任務」**：孩子看得到的字卡本裡有任務的，每天輪到幾個（預設四個，手機最多放三個），點進去就直接開那本的任務，完成的那張磚右上角打勾。
它只是捷徑，任務就是字卡本裡的「任務」模式，不是另外一份教材。怎麼輪（`src/utils/missionPlan.ts`）：

- 不同分區的任務盡量混在一起（每個分區的任務平均散開再輪），不會一天四個全是英文單字
- 每個都輪過一圈才會再輪到，不會有排不到的
- **每個任務裡的每張卡也都輪得到**：同一個任務每排上首頁一次，認識的卡就換下一張，張數再多都輪得完
  （不用日期算：任務六天才輪到一次的話，日期除以張數的餘數會一直落在同幾張，六張卡的字卡本就永遠只認識同一張）。
  片單用 `認識:` 固定了哪一張的任務不受影響
- **題目也會換**：同一本字卡下面寫好幾行 `任務:`，就有好幾個題目（見下面的寫法），每排上首頁一次換一個題目；
  卡片轉完一圈，題目再多偏一格，所以每張卡都會遇到每個題目（只寫一行的字卡本，題目就一直是那一句，只有認識的卡會換）
- **學校教的優先**：家長設了字母進度、或釘選了某些任務（見下面），這些就算「學校教的」，每天優先佔一半的位子（4 個放 2 個、3 個放 2 個、2 個放 1 個；
  一天只放 1 個的時候，學校教的和其他的隔天輪流），排在前面；其餘位子照上面的方式輪別的。學校教的和其他的各輪各的、各補各的；
  某一邊任務不夠放，位子讓給另一邊。沒設的話跟以前一樣，全部一起輪
- 昨天排了卻沒做完的，今天優先補上**一次**（最多佔一半的位子；一天只放一個的時候不補），補過就不再補，不然孩子一直不做，同樣幾個會永遠釘在首頁。補上的還是昨天那一張卡
- 同一天不管開幾次、中間做完幾個，都是同一批；今天排了哪幾個、輪到哪裡、每個任務排過幾次記在這台裝置上（`kidtube.missionToday`）
- 孩子這一班的任務很少的時候（例如大班只有 4 個），一天放的個數比任務還多就每天全放，只是每次換一張卡

**今日任務一直開著**，下面是大分類圖示（見上面「兩個畫面」）。點進某個大分類時，任務收起來、整個畫面留給那一區；
玩完字卡回來會停在原本那個大分類，重新打開 App 才回到首頁。今天沒有任務可以放（全部被標成不排）的時候，首頁就只有大分類圖示。

**家長設定 →「小朋友」→「今日任務」**：
- 每天放 1～4 個
- **學校教到哪個英文字母**：選「教到 J」，字母任務（單元名稱有 ABC 的字母卡）就只用 A～J 的卡來認識，而且自動算學校教的、優先排進首頁；
  學校教到新的字母再來改。（字母卡沒有任何卡在限制範圍內的話，就不限制，不會空掉）
- **📌 學校這週教的**：每個任務右邊的圖釘，亮起來的優先排進首頁；剛按下去今天就排進來，不用等輪到。學校換單元就取消
- 把家裡做不到的任務（例如沒有動物玩偶可以找）取消打勾，就不會排進首頁。任務有一百多個，所以依分區分成一組一組，點標題展開
- **改題目、新增題目**：「片單」頁展開某一本字卡（✏️ 編輯卡片和任務），最下面的「任務題目」可以改每個題目的中文句、英文句、
  要做什麼（找／放／做）、按幾次、給爸爸媽媽的提示，也能新增或刪除題目。沒有任務的字卡本（例如卡通）加一個題目就排得進去；
  題目全部刪掉，這本字卡就不排進今日任務。改的存在這台裝置，試算表更新之後也會保留，「還原成試算表的內容」可以退回去

改了馬上生效，今天已經排好的其他幾個不會跟著變。只影響首頁的「今日任務」，貼紙本裡還是看得到、點得開。
這份設定（`kidtube.missionPlan`）只存在這台裝置上，跟孩子的年紀一樣，不會跟著片單同步。
貼紙和完成次數也記在這台裝置上（`kidtube.missions`）。

**任務貼紙本**：今日任務標題右邊的 🏅「貼紙本 3/170」（任務完成的畫面也有一顆），點進去是孩子這一班所有任務的貼紙：
完成過的是彩色貼紙、右上角寫完成幾次，還沒做過的是淡淡的空圈。點任何一張都直接開那個任務，想把空圈貼滿就一個一個去做。

片單寫法，寫在 `字卡本:` 下面，一行：

```
字卡本: 顏色 Colors
階段: 幼幼班
任務: 家裡找找看，有哪些{zh}的東西？ | Find something {en} at home! | 找:3 | 提示:衣服、玩具、杯子、水果都算
```

| 欄位 | 說明 |
|---|---|
| 中文那句、英文那句 | 有中文字的是中文、英文句子是英文，順序不拘。中文、中英模式說中文，English 模式說英文；只寫一種的話另一種先用同一句，建置檢查會提醒 |
| `{zh}`、`{en}` | 換成這一次認識的那張卡的名字（紅色、red；數字卡是「三」、three）。顏色、形狀、動物這種一本好幾張的，一行任務就涵蓋每一張卡 |
| `{abc}` | 換成這張卡開頭的字母（apple → A），字母卡的任務用：`家裡有什麼東西是 {abc} 開頭的？` |
| 好幾行 `任務:` | 同一本字卡寫幾行就有幾個題目，第一行是主要的（家長設定裡顯示的那一句），每次排上首頁換一個；每一行各自有自己的動作、找幾個、提示 |
| `認識:bus` | 固定先認識哪一張卡（卡片上的字）；**沒寫就每次換一張**（首頁「今日任務」每排上去一次換下一張，磚上看到的就是點進去認識的那張） |
| `找:3` | 要找幾個，1～10，沒寫是 3。`找:數字` 是找的個數就是卡片上的數字（數數的任務：認識「3」就拿三個東西一個一個數） |
| `動作:做` | 小朋友要做的是哪一種事：`找`（預設，按鈕寫「我找到了」）、`放`（把東西放回去，「我放好了」）、`做`（刷牙、看時鐘、做一件環保小事，「我做到了」）。話裡有 `{place}` 的自動是放 |
| `提示:…` | 給家長看的一行：哪些東西算、怎麼陪孩子玩，小朋友看不懂也不會唸 |

**分區預設任務，不用每本都寫**：`任務:` 寫在 `【分區】`（或 `# 大分類`、`## 冊`）下面、第一本 `字卡本:` 之前，
底下所有沒有自己寫 `任務:` 的字卡本都用它（最近的一層優先；新加的字卡本自動就有任務）。不要任務的字卡本寫 `任務: 無`；
分區整個都不要（例如卡通）就在分區下面寫 `任務: 無`：

```
【第 1 級】🌱
階段: 幼幼班～中班
任務: 家裡找找看，哪裡有{zh}？真的、玩具、書上的圖片都可以！ | Can you find the {en}? A real one, a toy or a picture is OK! | 找:2
任務: 看著圖片，大聲說三次：{zh}！再用英文說說看。 | Look at the picture. Say "{en}" three times! | 動作:做 | 找:1

// 身體不適合「家裡找找看」，這一本自己寫：
字卡本: 身體 Body
任務: 摸摸自己的{zh}，再說：這是我的{zh}！ | Touch your {en}. Say: This is my {en}! | 動作:做 | 找:1
```

現在 176 本字卡本裡 170 本有任務（只有 6 本卡通沒有）。依類型分成：東西（找找看、說三次、畫一畫）、句子和動作（一起練習、演演看）、
數字（拿出幾個數一數、在空中寫數字、找數字）、注音和國字（找這個字、在空中寫、組詞）、身體、家人、職業、地方、相反詞、押韻、地圖（世界各國、七大洲）……
個別不適合的各自寫專屬題目。

### 放哪裡：把東西拖到對的地方

認識家裡每樣東西住哪裡：碗在廚房、牙刷在浴室、鞋子在門口。卡片寫了 `放:` 的字卡本，上面多一顆 🏠「放哪裡」（要有 4 張以上、2 個以上不同的地點）：

- App 問「Where does the bowl go?／碗要放在哪裡？」，畫面上是那樣東西的照片，下面是兩三個地方的照片
- 小朋友**把東西拖到對的地方**，或**直接點那個地方**（幼幼班手指小、拖不準，點也一樣算）
- 放對了：東西縮小飛進那個地方、說「Put the bowl in the kitchen.」、拿一顆星；
  放錯了：東西彈回原位、說「Hmm, not that one. This is the bathroom. Try again.」再問一次，**不說 No**。放錯的東西這一輪最後再考一次
- 一輪最多八題；玩完如果這本有「放東西的任務」，會多一顆「真的放放看」：用最後放對的那樣東西開任務，
  App 說「把鞋子拿去門口，放放看！」，小朋友真的拿去放，回來按「我放好了」

片單寫法：每張卡最後加一欄 `放:地點`，地點寫中文名或英文名都可以（認得廚房 kitchen、浴室 bathroom、臥室 bedroom、門口 door、客廳 living room）：

```
卡: bowl | 碗 | cards/real/bowl.webp | Eat soup from the bowl. | My bowl is blue. | The bowl is full of rice. | 放:廚房
```

放東西的任務，話裡寫 `{place}`（中文地點）和 `{where}`（英文片語 in the kitchen／by the door）：

```
任務: 把{zh}拿去{place}，放放看！ | Put the {en} {where}! | 找:1
```

有 `{place}` 的任務按鈕寫「我放好了」，認識的卡也只從有寫 `放:` 的裡面挑。只找一個的任務（`找:1`）不會唸「One!」。

- 目前有一本：認識世界 › 一起生活 › 「東西放哪裡」（幼幼班～中班，11 樣東西、4 個地方）
- **東西要選一定放在那裡的**：碗、杯子、湯匙在廚房，牙刷、肥皂、毛巾在浴室，枕頭、毯子在臥室，鞋子、雨傘、書包在門口。
  每家習慣不同的（書、玩具、遙控器）先不放，孩子才不會被考倒
- 地點登記在 `src/utils/places.ts`（要新增客廳、陽台之類的在那裡加），地點的照片是 `public/cards/real/place-kitchen.webp` 這樣的檔名。
  **想換成自己家的廚房、浴室**：拍好丟進 `drive/real/`，取一樣的檔名（`place-kitchen.jpg`）再跑 `node scripts/make-real-cards.mjs`，就蓋掉了
- 程式：拖曳、放對放錯的流程在 `CardDeck.vue` 的「放哪裡」；任務代入 `{place}` 在 `utils/cards.ts` 的 `missionTextOf`

### 排順序：照順序一張一張點

卡片本身就是依順序排的字卡本（洗手步驟、一天作息、地震怎麼辦、星期、月份、四季、一天的時間、時鐘整點、認數字 11～20……），
字卡本下面寫一行 `順序: 是`，上面就多一顆 🔢「排順序」。小班到大班的「步驟、順序」就是從這裡練：

- 每題從這本裡挑**連著的三張**（洗手步驟的「搓一搓、搓指縫、沖乾淨」；七月、八月、九月），**打亂**擺在下面，上面是三個編號 1、2、3 的格子
- App 問「What comes first?／哪一個最先？」，小朋友點最先的，那張飛進第 1 格，App 說它的名字，再問「What comes next?」；
  點完第二張，最後一張自己放進第 3 格
- 點錯了：那一張輕輕晃一下、說「Hmm, not that one. Try again.」，再問一次，**不說 No**
- 排好之後把三樣照順序唸一遍（「搓一搓，搓指縫，沖乾淨」），一次就排對拿一顆星；一輪最多五題（卡少的字卡本題數就少：四季只有兩題）

```
字卡本: 洗手步驟 | Hand Washing Steps
階段: 幼幼班～小班
順序: 是
卡: wet your hands | 弄濕雙手 | 💧 | …
```

**卡片要照正確的順序寫**（程式就是靠寫的順序判斷誰先誰後）；有些卡本只有前半是順序的（植物：種子→嫩芽→葉子→花→樹，後面是別的植物），就不要標。
想關掉寫 `順序: 否`。程式：解析在 `src/utils/playlist.ts`，遊戲在 `CardDeck.vue` 的「排順序」。

### 比一比：哪一邊比較多？哪一個數字比較大？

不用另外設定，卡片是數字的字卡本會自動多一顆 ⚖️「比一比」（同一本要有 6 張以上），兩張並排，小朋友點對的那一張：

- **數一數的字卡本**（數一數 1～10、海洋、交通工具、11～20、蟲蟲，卡片是 emoji 加數字）：兩堆一樣的東西，五個一排，
  問「Which has more?／哪一邊比較多？」。**數字先不寫**，要自己數、自己比；答完才亮出兩堆各是幾個
- **純數字的字卡本**（認數字 11～20、十個十個數、0～100）：兩個大數字，問「Which number is bigger?／哪一個數字比較大？」
- 「比較多、比較大」和「比較少、比較小」輪流問（第 3、5 題問少），不會學成「選多的就對」；前三題兩邊差得多，後面才有差一點點的
- 答對了說「Seven is more than four.／七比四多。」，點錯了說「This is four.」再問一次，**不說 No**；一輪六題，一次就對拿一顆星
- 程式：`CardDeck.vue` 的「比一比」；有圖的數字卡（數字像什麼）、有影片片段的卡不算，所以只靠卡片本身就判斷得出來

### 練習：數一數、找出所有的 6、用手指描一描

靈感來自幼兒園的學習單（數數、圈出所有的 1、圈出有 3 個的圖案、找出所有的 b、跟著線條畫一畫）。
**一個畫面只問一題**，一輪六題、題型混著出（相鄰不會連著同一種）；**不用在試算表多寫任何東西**，由字卡本自己的卡自動出題，
符合的字卡本多一顆 ✏️「練習」。小朋友是動手數、找、拿、描，不只是點對錯。

| 題型 | 怎麼玩 | 哪些字卡本有 |
|---|---|---|
| 數一數 | 一堆東西撒在板子上，**每點一個就唸一個數字**（點過的標上第幾個），再從三個數字選有幾個 | 數一數的字卡（emoji 加 1～20） |
| 哪一堆 | 三堆不同的東西、不同的數量，聽到「哪一堆有 6 個？」點出來；旁邊大大寫著數字，數字和數量對起來；答完亮出每一堆是幾個 | 數一數的字卡（最多 10 個） |
| 給我幾個 | 「給我三個！」把東西點到籃子裡，**每點一個唸一個數字**，按「好了」才算；拿多、拿少都說「你拿了四個」，東西留在籃子裡自己加或拿出來 | 數一數的字卡（最多 12 個） |
| 找出所有的 | 九格裡找出全部的 6（旁邊混著 9）或 b（旁邊混著 d），**每找到一個唸一個數字**，找完最後那個數字就是「一共有幾個」 | 數字卡、ABC 字母卡 |
| 描一描 | 淡淡的字加點點外框，用手指照著描 | 數字、字母、注音、國字（國字、注音只出描一描，一輪四題） |

- **容易搞混的先放進干擾項**：6 和 9、b 和 d、p 和 q、31 和 13、2 和 5……（`utils/practice.ts` 的 `DIGIT_LOOK`、`LOOK_LOWER`、`LOOK_UPPER`）。
  「考考我」的數字選項也加了：答案是 6，選項一定有 9
- **學校教到哪個字母**（家長設定「今日任務」的字母進度）：字母只用 A～那個字母出題，干擾的字母也先挑教過的
- 字母卡大小寫輪流出；描一描不放第一題（先暖身）、最多兩題（只有「找出所有」和「描一描」兩種的字卡本最多三題）
- 規矩跟其他模式一樣：不說 No、點錯說「這是九」再問一次（點過的錯誤再點只唸它是什麼）、一次就對拿一顆星、一輪結束有鼓勵
- **描一描怎麼判斷描完**：把字縮成 128 像素寬的形狀，算筆畫大約多粗（面積÷周長），三個條件都要：整個字描到 7 成以上；
  **字的每一個部分都要描到**（字分成 6×6 區，有字的每一區都要描到一半以上，所以「5」只描豎線和彎、沒描上面那一橫不算過）；落在字外面的筆畫不到 4.5 成（整張亂塗不算）。
  畫過一次之後出現「確定」（English 是 OK）：孩子說描好了、或描不出來，按了就結束這一題，說一句鼓勵再唸這個字，不會卡住（還沒描完整的沒有星星，描完整會自己過）；↺ 清掉重畫。畫布用系統的圓體字（Arial Rounded、PingFang），不用另外準備筆順資料
- 程式：出題在 `src/utils/practice.ts`（可以用 rolldown 打包後在 Node 測）、畫面在 `src/components/PracticeBoard.vue`；App 說的固定句子在 `utils/cheers.ts` 的 `PROMPTS`（可以錄成爸媽的聲音）

### 聽聲音：動物真正的叫聲

以前「牛怎麼叫」只是合成語音唸 `Moo!`；現在卡片最後寫了 `聲:` 的字卡本，會放**動物真正的叫聲**（要有 4 張以上）：

- **看卡片**：翻到背面，唸完名字和句子就接著放真正的叫聲；卡片下面多一顆 🔊「叫聲」，想再聽一次就按
- **聽聲音**（上面多一顆 🔊 按鈕）：App 說「Listen!」→ 放叫聲 →「Who is it?」，小朋友從三張動物照片裡點出是誰；
  點對了說名字、再放一次叫聲當獎勵；點錯了說「This is a horse.」、再把叫聲放一次。題目和選項都只從有叫聲的卡裡挑，一輪最多八題，一次答對拿一顆星
- 叫聲是音檔，不是語音，所以**不分中文、英文**，也**不是爸媽錄的**（爸媽錄音只管 App 說的話）。想用自己的聲音學牛叫，
  直接把自己錄的丟進 `drive/sounds/` 換掉就好

片單寫法：卡片最後加一欄 `聲:音檔路徑`（要是 wav、mp3 或 m4a；ogg 在 iPad 放不出來，`npm run check-sheet` 會提醒檔案不存在、格式不對）：

```
卡: cow | 牛 | cards/real/cow.webp | Moo! I am a cow. | The cow gives us milk. | The cow eats grass. | 聲:cards/sounds/cow.wav
```

音檔放在 `public/cards/sounds/`，用 `scripts/make-sound-cards.mjs` 轉：

- 把原始音檔（ogg、mp3、wav、m4a 都可以，iPhone 錄的 m4a 也行）丟進專案根目錄的 `drive/sounds/`（已在 `.gitignore`），檔名用英文小寫（`cow.m4a`），
  跑 `npm i --no-save puppeteer-core`（只要裝一次）再 `node scripts/make-sound-cards.mjs`，會轉成 `public/cards/sounds/cow.wav`
- 自動剪掉前後的靜音、最長 4 秒、結尾淡出、轉成單聲道 16kHz（一個約 60～130KB）、音量調成一樣大聲（每個叫聲不會有的特別大聲嚇到小朋友）。
  一個檔裡有好幾聲、只要其中一聲，在 `scripts/sound-sources.json` 那個名字裡寫 `"parts": [[開始秒, 結束秒]]`
- 目前「農場動物」那本有牛、豬、狗、貓、鴨、雞、綿羊、馬 8 種叫聲（山羊、兔子沒有：山羊找到的是一整群羊的嘈雜錄音，不是乾淨的單一叫聲，先不放；想要就自己錄一聲、補一欄 `聲:`），都是 Wikimedia Commons 的免費授權音檔，**作者和授權寫在 [`public/cards/sounds/CREDITS.md`](public/cards/sounds/CREDITS.md)**（CC BY／BY-SA 要標作者，不能刪）；
  **我沒辦法聽聲音，只用波形和頻譜圖挑「乾淨的單一叫聲」，請你用耳朵確認過**（不滿意的換自己錄的、或在 `sound-sources.json` 改 `parts`）
- 叫聲跟字卡圖片一樣，依孩子的年紀在背景存起來，沒網路也放得出來

### 照家裡的書做字卡：邊看書邊翻卡

「我的書」大分類（試算表的「藍色動物書」「紅色單字書」工作表）是照家裡的兩本書做的：**一頁一本字卡**，名稱就是書上那一頁的標題（`Pets 寵物`），
卡片的字、中文、順序照書上印的，**圖是從書頁照片裁下來的**：書上那一格整個截下來，連印在上面的標題、單字、中文都在（小朋友還不識字，不用遮）。小朋友把書攤在旁邊：

- **清單上的封面就是那一頁的照片**，看了就知道要翻到書的哪裡
- **打開字卡先秀出整頁**：「Open your book to this page!／把書翻到這一頁！」，翻好按「找到了！」才開始。看卡片時按 📖「這一頁」可以再叫出來
- **看卡片**：螢幕上是書上那一格的圖，小朋友在書上找到同一格、說說看是什麼，再翻面聽答案。
  一個場景裡有好幾個東西的（身體、家人、浴室、臥室、穿衣服），圖是整個場景加一個紅圈，圈到哪裡就是問哪裡
- **書上找**（有書頁的字卡本才有這顆按鈕）：反過來，App 問「Where is the hamster?」→「Find it in your book!」，
  畫面上先不放圖（看螢幕就知道答案了），他在**手上的書**裡找出來、指給你看，點圓圈之後 App 才秀出那張圖：「Here it is! Hamster.」。
  一樣不判斷對錯，順序打亂，一輪最多八個
- 「Who says what? 這是誰的聲音？」那頁的大字是叫聲（woof woof），正面問「What does it say?／牠怎麼叫？」

每一張字卡的圖，是從**原始照片**裁出來的（比整頁照片大 2～3 倍，所以清楚）：

- 整頁照片 `public/cards/books/<書>/<頁>.webp`：小朋友開字卡先看到的那一頁，只有 1100px 寬，不換。**這個資料夾不進 git，在 iPad 上靠「素材包」（見上面）**
- 原始照片放在專案根目錄的 `drive/`（有版權又大，已在 `.gitignore`，不進版控）；`scripts/book-photos.json` 記每一頁用哪一張、整頁照片在原始照片裡的位置（原始座標 = x0 + 整頁座標 × k）
- `scripts/book-crops.mjs` 記每一張卡的那一格（整頁照片上的 左、上、右、下），場景裡要圈出來的東西另外記紅圈的位置。一格連書上印的標題、單字、中文都截進來，小朋友還不識字，不用遮
- 每一格會自己找邊、拉正（書頁拍得有點斜）、四個角削成圓角（書上的格子就是圓角）。圖伸出格子外的（大象的鼻子、犀牛的角和尾巴、公雞的尾羽、鴨子的嘴），在 `book-crops.mjs` 把那一格的範圍手動往外擴，再列進 `OVERHANG`，那幾邊就不找邊
- 重裁：`npm i --no-save puppeteer-core`（不放進 package.json），再 `node scripts/crop-book.mjs`（全部）或 `node scripts/crop-book.mjs animals/pets`（一頁）。用 Chrome 的畫布處理，圖縮到最長邊約 800px，放大的才銳化邊緣；`--debug <資料夾>` 會另外存每一頁找到的格子邊，畫在照片上，方便檢查。`drive/` 不在的話可用 `--photos <資料夾>`；原始照片找不到的頁會退回用整頁照片裁，比較糊

要再加一本書：把每一頁拍下來，整頁照片放 `public/cards/books/<書>/<頁>.webp`，原始照片放 `drive/`，在 `book-photos.json` 補對位、在 `book-crops.mjs` 補每一格，再跑 `crop-book.mjs`。原始照片盡量正對著拍、光線均勻，裁出來的邊才不會帶到旁邊格子。
然後在試算表的「我的書」那幾個工作表，每一頁開一本字卡本，下面加一列類型「設定」寫 `書頁: cards/books/<書>/<頁>.webp`。圖片路徑打錯的話，`npm run check-sheet` 會提醒；新的圖記得重新打包素材包（`node scripts/pack-media.mjs`）、重新匯入。

   （例如 2 歲的小朋友在「中文」只看到小星星、兩隻老虎這些兒歌，注音、國字從中班才出現）
3. 想讓他提前玩下一班、或回頭複習：在「小朋友端顯示哪些階段」點那一班就開放，再點一次收起來；孩子這一班一直開著
4. 沒標階段的（自己加的影片、娛樂）一直都看得到

還沒設定出生年度的話，四個階段都顯示，等於不篩選。設定存在**這台裝置**上，每台裝置各自設定
（所以電視沒辦法設，見上面）。出生年月不會寫進片單，不會跟著公開網站出去。
家長設定頁的「目前片單」不受這個設定影響，上面另外有一排「全部／幼幼班／小班／中班／大班／不分年齡」可以只看某一班的。
每一筆標題下面的小標籤是它適合哪幾班，點一下就能直接改；也可以按住縮圖或標題一下，拖到上面那排的某一班放開，就換成那一班
（改的只存在這台裝置，試算表更新之後也會保留，要所有裝置一起改還是要改檔案；
見下面「方法二」的「在裝置上改內容」）。

`階段:` 只管它**正上方那一行**（分區、冊或那一支影片），不會往下延續。
例如「從 SF02 的 Father's Day 起都是中班」，要在 Father's Day 那一行下面寫一次，後面的《SF03》《SF04》再各自寫。

**自己加教材**：字卡本或影片寫完，在下面加一行 `階段: 小班～中班` 就好；沒寫的一直顯示。
在試算表加的影片也一樣，在那一列的「階段」欄填就好。

**影片**：每個主題底下的「影片」分區（數字 › 影片、英文單字 › 影片、中文 › 影片、認識世界 › 影片）照主題分成單元
（數數、時間、家人與生活、動物、吃喝玩穿、心情與動作、自然與安全、樂器與運動、節慶、卡通、中文兒歌、台語童謠、唐詩、恐龍與工程車……），
每支影片也標了適合哪幾班，所以小朋友只看到適合他的。好習慣的每張卡片另外接一首兒歌（卡片上的「看影片」）。
影片都是 YouTube 上的兒歌，挑官方或知名頻道（Super Simple Songs、Noodle & Pals、Jack Hartmann、Dream English、
Maple Leaf Learning、The Kiboomers、Sesame Street、Nick Jr. 等；中文的是 momo 親子台、YOYOTV、巧虎、公視台語台、
碰碰狐、貝貝彬和寶寶巴士的繁體中文頻道），加進來前都向 YouTube 確認過允許嵌入播放。
YouTube 上有很多人把別人的歌重新上傳（標題寫「Super Simple Songs」其實不是），新增時請認頻道名稱，不要只看標題。

**正面問的問題要跟答案對得上**：顏色問「What color is this?」、形狀問「What shape is this?」、心情問「How does he feel?」、
動作、運動、一天作息問「What is he doing?」、不舒服問「How does he feel?」、
家人、職業、親戚朋友、童話角色和卡通角色問「Who is this?」、地方、家裡的房間、世界各國、台灣好地方和七大洲問「Where is this?」、
天氣問「How's the weather?」、四季／星期／月份／時鐘問「What season／day／month／time is it?」、
一天的時間問「What time of day is it?」、
好習慣、好朋友、冷靜下來、上課口令、洗手步驟、健康小習慣、環保好習慣、安全守則、地震怎麼辦問「What should we do?」、
禮貌、見面問候、生活用語（名稱結尾是「怎麼說」）問「What do you say?」、卡通角色常說的話問「What do they say?」、
五感問「What can you do with it?」（正面是眼睛，答案是 see），
其他一般的東西問「What is this?」。中文模式也一樣（這是什麼顏色？／可以用它做什麼？）。
預設是看字卡本的名稱決定的（見 `src/utils/cards.ts` 的 `askKindOf`），**但每張卡可以自己改**：
同一本裡有幾張不適用那個問法時，在那張卡最後加 `問:東西`——天氣裡的雪人、雨傘是東西不是天氣，形狀裡的月亮也是，
這幾張就問「What is this?」。`問:` 後面可以寫：東西、顏色、形狀、心情、動作、該做什麼、說什麼、台詞、樣子、誰、哪裡、天氣、季節、星期、月份、幾點、時段、感官、叫聲，
或「問句」工作表自己加的名字。這些問句的英文、中文都在「問句」工作表那一列改。

**相反詞**問「Is it big or small?」：每張卡最後用 `對:` 指定另一半（`卡: big | 大 | 🐘 | … | 對:small`，small 那張也要寫 `對:big`），
兩個字誰先講每翻到一張卡隨機換（Is it big or small? ／ Is it small or big?），小朋友才不會學到「第一個講的就是答案」。
中文模式問「它是大還是小？」。另一半找不到的話，退回字卡本的問法。

**卡通角色**（英文單字 › 卡通）：波力救援小英雄、汪汪隊立大功、玩具總動員。每個角色一張卡，翻面唸角色常說的招牌句子
（Chase is on the case!／To infinity and beyond!）加簡單的介紹。圖用 emoji（🚓 警車、🤠 牛仔），**沒有放官方圖片**（有版權）；
想換成自己的圖，放進 `public/cards/`，片單裡把 emoji 換成圖片路徑就好。
汪汪隊小狗的中文名字各地譯名不一樣，所以只寫他們的工作（警察狗狗、消防狗狗……）。

每個卡通後面再接一本「**常說的話**」（波力常說的話、汪汪隊常說的話、玩具總動員常說的話）：整句台詞一張卡，
像 `Ryder needs us!`（萊德需要我們）、`PAW Patrol, to the Lookout!`、`Chase is on the case!`、`Safety first!`、`To infinity and beyond!`，
圖是兩三個 emoji 畫出情境（📱🐶 萊德來電、🐶🚓🔍 警察狗狗查案），
正面問「What do they say?」，翻面除了台詞，另外兩句是生活裡怎麼用（`Hurry, pups! Ryder needs us.`）。

### 方法二：直接在裝置上的「家長設定」增減

長按齒輪 1.5 秒，輸入 4 位數密碼（預設 `1234`，可在設定頁改），
進去之後可以線上加影片、拖曳排序、新增/刪除分區，改錯還能用「復原」一步步退回去。

**在裝置上改內容**：「目前片單」每一筆標題下面有一顆「✏️ 編輯」：

- 影片：改標題、換 YouTube 網址（貼上就看得到新的縮圖）
- 網站：改標題、網址
- 字卡本（「✏️ 編輯卡片」）：點一張卡打開來改**字、中文、圖（emoji 或 `cards/` 開頭的圖片路徑）、英文句子**（一行一句）和
  **正面問的問題**（「這是什麼？」問錯了改成「這是誰？」；每張卡各自選，或在卡片清單上面的下拉一次改整本、也可以全部退回照字卡本名稱的自動問法），
  也能新增、刪除、按住把手拖曳排序。影片片段、唸法、相反詞、放哪裡這些這裡改不到，會照原樣保留；
  中文識字卡（正面固定問「這個字怎麼唸？」）和相反詞（問「Is it big or small?」）不看問法，就不列出來

先改草稿，按「儲存」才算數（算一步，可以復原）。改過的會標「這台改過」，
**只存在這台裝置，但試算表更新（部署新版）之後也會保留**：同步時先換成檔案的內容，再把這台改過的標題、網址、字卡、
適合的班級套回去。試算表後來也改了同一筆的話，現在用的還是這台的版本，編輯區會提醒；
要用檔案的版本，按編輯區的「還原成試算表的內容」，或「來源備份」頁「學習單」面板的「全部還原成試算表的內容」。
檔案裡已經找不到的那一筆（字卡本改了名字、影片刪掉了），這台的修改就不留了，同步結果會說有幾筆。
搬移、排序、新增和刪除還是跟以前一樣，試算表一改過就以試算表為準。

要每台裝置都一樣，還是要改試算表。

程式：改過的地方記在 localStorage 的 `kidtube.localEdits`（`src/composables/useLibrary.ts` 的 `LocalEdit`），
編輯區是 `src/components/ItemEditor.vue`。復原紀錄只存每一步改到的部分（整份片單有幾十萬字，以前每一步存一份完整的，
十幾步就把 localStorage 塞滿了）。

## 帶出門（沒網路也能用）

平板從 Chrome 安裝成 App 之後，**字卡、數一數、考考我在沒網路的地方也都能玩**：
App 本身在安裝（或部署更新）時就下載到平板上（不到 1MB）；`public/cards/` 的字卡圖片全部加起來約 6MB，
**不會整批下載**，只會依**孩子的年紀**，在有網路時於背景存下他這一班（加上家長另外開放的班）用到的：

- 家長設定 → 小朋友 → 孩子的年紀，設了出生年度，就只存他這一班的；換了年紀、另外開放別班，會自動補存新的那幾班
- 還沒設定出生年度，四個班都開放，就會全部存（跟以前一樣）
- 其他班的圖片不會事先下載；用到時才從網路抓，順便存起來
- 省多少看片單怎麼標階段：**標了階段的才會被篩掉**。例如「我的書」寫的是 `階段: 全部`，那兩本書的圖（約 5MB）每一班都會存；
  想讓書的圖也依年紀少存一點，把書的階段標成適合的班（例如 `階段: 小班～大班`）

1. **出門前**在有網路的地方打開 App 一次（剛部署新版的話，這一步會補存新的圖）
2. 進家長設定 → 這台裝置 →「離線使用」，看三項都打勾：網路、App 本身、字卡圖片 N / N 張存在這台裝置
   （N 只算孩子這幾班的）。圖片還沒存齊的話，按「把這幾班的字卡圖片存到這台裝置」
3. **Android 平板的語音**：到「設定 → 系統 → 語言 → 文字轉語音輸出」，按 Google 語音服務旁的齒輪 →
   「安裝語音資料」，下載**英文（美國）**和**中文（台灣）**，沒網路時才唸得出來（各家平板選單名稱略有不同）。
   iPad 的語音本來就在裝置上，不用設定
4. 不放心的話，開飛航模式再打開 App 試一次

沒網路的時候：片單上的影片和網站會變淡，點了會說「現在沒有網路，影片不能看。先玩字卡吧！」；
字卡上的「看影片」按鈕會先藏起來。**YouTube 影片本身沒辦法離線**，這是 YouTube 的限制。
App 也會請 Chrome 把資料標成「要保留」，平板空間不夠時才不會把字卡圖片清掉。

| 素材（素材包／雲端硬碟資料夾） | 書頁圖片、叫聲放自己的雲端硬碟（做成 zip 匯入一次，或放一個資料夾按同步），存在裝置上、離線也能用；不放公開的 GitHub，沒有版權疑慮 |
| Google 試算表片單 | 學校教材、不想放公開 GitHub 的片單：一個工作表一個分區，家長在手機上改，iPad 直接讀，不經過 GitHub、不用 API 金鑰 |
| 也能放網站 | 片單裡可以放學習網站，在 App 內開啟，小朋友不會跳出去 |
| 字卡 | 把學過的數字、單字做成卡片：翻卡、點著數、中英文一起唸再加一句簡單英文、看影片片段、考考我集星星 |
| 改錯可復原 | 家長設定頁的「復原」可以連按一路退回去（最多 15 步） |
| 亮色／暗色 | 預設跟隨系統（iPad 的外觀設定），小朋友端一鍵切換、家長設定也能固定成亮色或暗色 |
| 每日時間上限 | 預設一小時，用完自動停播並鎖住片單，隔天自動重置 |
| 強制休息 | 預設每看 15 分鐘休息 2 分鐘；時間到時正在播的那部先看完（或按返回離開）才休息，不在中途硬停，倒數完才能繼續 |
| 家長門禁 | 長按齒輪 1.5 秒 + 4 位數密碼才進得去設定；首頁的 🎬 鎖頭鈕輸入同一組密碼才進影片時間 |
| 家長設定分頁 | 設定分成「觀看時間／片單／分區／小朋友／照片素材／這台裝置／來源備份」七頁，一次只看一類，不用一直往下捲 |
| PWA | 加到主畫面後全螢幕執行，沒有網址列與分頁 |
| 字卡離線 | `public/cards/` 的圖片依孩子的年紀在背景下載（全部約 6MB，大部分是「我的書」的書頁和裁好的圖），只存他這幾班用到的，沒網路也能翻字卡、考考我；YouTube 影片沒辦法離線 |
| 依年紀顯示 | 每本字卡、每支影片標了適合幼幼班到大班的哪幾班；家長設定孩子的出生年度，小朋友端的每個主題就只顯示他這一班，其他班另外開放 |
| 識字卡 | 注音、國字：正面只寫字，翻面才有圖和說明，一律唸中文 |
| 我的書 | 照家裡的書一頁一本字卡，圖跟書上一模一樣；打開先翻到同一頁，「書上找」聽到名字就在書裡找出來 |
| 生活任務 | 認識一個東西（真實照片）→ 離開螢幕到家裡找幾個 → 回來按「我找到了」→ 貼貼紙；首頁「今日任務」每天輪幾個（家長可調，預設四個），去找的時候不算觀看時間 |
| 放哪裡 | 把碗拖到廚房、牙刷拖到浴室：真實照片配真實地點，拖不準也可以直接點；玩完接著真的把東西放回去 |
| 聽聲音 | 放動物真正的叫聲，從照片裡點出是誰；翻面也會放叫聲（農場動物：牛、豬、狗、貓、鴨、雞、綿羊、馬） |
| 排順序 | 洗手步驟、一天作息、星期、月份這類本來就有順序的字卡：每題三張打亂，照順序一張一張點，三樣排好再唸一遍 |
| 比一比 | 數一數的字卡比哪一邊比較多／少（不寫數字，自己數），純數字的字卡比哪個數字比較大／小，答完說「七比四多」 |
| 練習 | 一個畫面一個題目、題型混著出：數一數（點著數、每點唸一個數字）、哪一堆有幾個、給我幾個（拿到籃子裡）、找出所有的 6／b（旁邊混著 9／d）、用手指描一描；由數字卡、ABC 字母卡、注音、國字自動出題，不用多寫試算表 |
| 任務貼紙本 | 每完成一個生活任務貼一張貼紙；孩子這一班所有任務排成一本，貼過的彩色、沒貼的是空圈，點一下就去做 |
| 家裡的照片 | 在 iPad 上拍照或選照片，換掉字卡的 emoji、網路照片和放哪裡的地點照片；縮小、轉 JPEG（HEIC 也轉）、去掉位置資訊後存在這台裝置，可以隨時還原預設圖 |
| 共用資料夾 | 「存到共用資料夾」自動用卡上的字取檔名（`apple.jpg`）交給分享選單；另一台「從資料夾匯入照片」用檔名對卡。不連雲端、沒有金鑰 |
| 資料夾同步 | 進階、選填：填 Google 雲端硬碟資料夾網址＋自己的 Google API 金鑰，按「立即同步」才把資料夾裡的素材（子資料夾的圖片、聲音）、照片和錄音（最上層）下載下來；只讀、只抓有變的、素材在雲端硬碟上刪掉的這台也刪（錄音只加不刪）、金鑰只存在這台 |
| 備份與還原 | 照片、錄音、在這台改的設定包成一個檔，自己存到「檔案」或 Google 雲端硬碟；可設密碼加密，還原前先檢查，家長密碼不放進備份 |
| 圖片與聲音來源 | 家長設定「來源備份」頁列出每一張照片、每個叫聲的作者、授權和連結（CC BY／BY-SA 要標作者） |

## 專案結構

```
src/
  App.vue              主畫面（library / watch / site / parent 四個畫面切換）
  app.config.ts         起點：沒有任何書單（書單在試算表）
  components/           LearnHome / FunLibrary / ShelfBrowser / VideoStage / SiteStage / CardDeck / StickerBook / ParentPanel / ItemEditor / CreditsList / PinLock / PanelSection
  composables/           狀態邏輯：片單、觀看時間、主題、家長門禁、拖曳排序…
  utils/                 YouTube 網址解析、書單文字解析器（playlist）、Google 試算表（sheetSource、xlsx）、字卡、語音、錄音（recordings）、照片（photos）、備份（backup）
docs/
  學習庫約定.md          字卡、階段、任務、問法的寫法和約定
scripts/
  check-sheet.mjs        檢查試算表有沒有寫錯（npm run check-sheet -- <試算表連結>）
  make-template.mjs      產生給其他家長的書單試算表範本（public/template/booklist-template.xlsx）
  pack-media.mjs         把書頁圖片、叫聲打包成素材包 zip（放自己的雲端硬碟，iPad 匯入；zip 解壓縮後也能當資料夾同步的內容）
  lib/xlsx-writer.mjs    寫試算表 xlsx（範本用）
  make-real-cards.mjs    把真實照片（drive/real/）轉成字卡用的 webp（public/cards/real/），也重產 CREDITS.md
  make-sound-cards.mjs   把叫聲音檔（drive/sounds/）剪好轉成 wav（public/cards/sounds/），也重產 CREDITS.md
public/
  cards/                 字卡用的圖片
  icons/                 PWA 圖示
```
