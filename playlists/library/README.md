# 學習庫

小朋友端「數字」「英文單字」「中文」「認識世界」這幾個主題的字卡和兒歌都在這裡，一個主題一個檔：

| 檔案 | 內容 |
|---|---|
| [`1-數字.txt`](1-數字.txt) | 認數字、數一數、數字在身邊、時間（四季、星期、時鐘、月份），和數數的兒歌 |
| [`2-英文單字.txt`](2-英文單字.txt) | ABC、第 1～3 級單字、卡通角色，和英文兒歌 |
| [`3-中文.txt`](3-中文.txt) | 注音、國字，和中文兒歌、台語童謠、唐詩 |
| [`4-認識世界.txt`](4-認識世界.txt) | 大自然、我自己、一起生活、世界各國，和相關的兒歌 |

家長自己的影片放 [`../videos.txt`](../videos.txt)。`npm run dev`、`npm run build`（GitHub 部署時也一樣）
會照檔名前面的數字把這幾個檔接起來，最後接 `videos.txt`，合併成 App 讀的 `public/playlist.txt`。

## 加新的東西

- **加一本字卡、一支影片**：打開對的檔，加在對的分區裡，下面寫一行 `階段:`
- **加一個新主題**：新開一個檔，例如 `5-音樂.txt`，第一行寫 `# 音樂 🎵`。檔名前面的數字就是小朋友端主題的順序
- 同一個大分類（`# 英文單字`）寫在兩個檔也可以，會併成一個；同一個大分類裡名字一樣的分區（【影片】）也會併在一起
- 字卡本的星星記在「大分類 › 分區 › 字卡本名稱」上：新的分區、字卡本加在哪裡都不會影響別本的星星，
  **改了字卡本的名稱，那一本的星星才會歸零**（`字卡本: 中文名 | English name` 的英文名稱不算）

## 改完怎麼知道有沒有寫錯

`npm run dev`、`npm run build` 之前會用 App 同一支解析器把片單讀一遍，看不懂的行會指出是哪個檔的第幾行：

```
片單檢查：有 1 個地方要看一下（不影響建置）
  ⚠️  playlists/library/2-英文單字.txt 第 312 行：看不懂階段「小斑」（要寫幼幼班、小班、中班、大班），已略過。
```

直接在 GitHub 網頁上改的話，部署的執行結果（Actions）會用黃色的 warning 標出來。
下面「同一個字用同一組句子」那條約定也會一起檢查。只提醒，不會擋住部署。

## 寫法

基本寫法（`#` 大分類、`【】` 分區、`《》` 單元、`卡:`、`字卡本:`）見最外層的 [README](../../README.md#直接編輯)。
學習庫另外有這些約定：

### 結構

- 「`# `」開頭是最上層的大分類（主題），`【】` 是大分類底下的分區；`字卡本:` 開一本新的字卡，同一區的排在同一個畫面
- `字卡本: 中文名 | English name` 的英文名稱是給全英文模式顯示的；名稱本來就有英文的（`農場動物 Farm`）不用另外寫
- 影片放在每個主題自己的 `【影片】` 分區，不跟字卡混在一起，小朋友練字卡時才不會分心

### 階段（適合哪幾班）

- `階段: 小班～中班` 寫在字卡本或影片的下面，標這一本適合幼幼班、小班、中班、大班的哪幾班
  （可以寫 `幼幼班`、`小班、中班` 或 `小班～大班`，`全部` 是四個班都適合）
- 家長在設定頁填孩子的出生年月，小朋友端的每個主題就只顯示適合他這一班的；想看別班的，家長在設定頁另外開放
- 沒寫階段的一直顯示。寫在分區或冊下面的話，底下沒另外標的都跟著它
- 幼幼班 2～3 歲、小班 3～4 歲、中班 4～5 歲、大班 5～6 歲（9 月 1 日那天滿幾歲）

### 難易度

- 每一區裡的字卡本照「簡單 → 有一點難」排：小朋友從最前面那本開始，熟了再往後
- 英文單字分成第 1～3 級：第 1 級是每天都看得到的東西，第 3 級是心情、動作這種摸不到的字
- 「認識世界」不照單字難度分，照認識什麼分（大自然、我自己、一起生活、世界），每本一樣標了階段

### 英文字卡的句子

- 卡片最後用 `.` `!` `?` 結尾的英文是句子，English 模式翻面時接在單字後面唸：`Apple. Yum, delicious apple!`
- 每張卡寫三句（每句一欄，用 `|` 隔開），每次翻到這張卡就換下一句
- 句型盡量錯開：叫聲（`Moo!`）、It can／has／is、問答（`Do you like…?`）、`Let's…`、打招呼（`Hello, little duck!`）
- **同一個字在不同字卡本用同一組句子**（cat 在「農場動物」和「動物 ABC」說一樣的話）。建置時會檢查，
  同一個英文字、同一個中文意思但句子不一樣的會提醒。同一個英文字不同意思的不算（light 電燈／light 輕）

### 正面問什麼

- 看字卡本名稱決定：顏色問 `What color is this?`、形狀問 `What shape is this?`、心情問 `How does he feel?`、
  五感問 `What can you do with it?`、世界各國問 `Where is this?`……（見 `src/utils/cards.ts` 的 `askKindOf`）
- 同一本裡有幾張不適用那個問法時，在那張卡的最後寫 `問:東西`（天氣裡的雪人、雨傘問 `What is this?`）
- 相反詞每張卡最後寫 `對:small` 指定另一半，正面問 `Is it big or small?`（兩個字誰先講每次換）
- 名稱有「相反」「四季」「星期」「月份」「時鐘」「習慣」「禮貌」「五感」「好朋友」「冷靜」「世界各國」的，
  卡片上不是「一個東西」，問的時候不加 the（`Where is Monday?`、`Where is Japan?`）

**開新的字卡本，名稱要跟這些關鍵字對得上才會問對**——例如想再開一本「好習慣 2」，名稱裡留著「習慣」兩個字；
要開一種全新的問法，得在 `src/utils/cards.ts` 的 `askKindOf`、`isBareDeck` 加關鍵字。

### 識字卡（中文字、注音）

- 第一欄是中文字或注音的卡叫「識字卡」，正面只寫那個字，翻面才有圖和說明，一律唸中文，不分語言
- 注音符號單獨唸，語音不一定唸得準，所以用 `唸:` 寫一個同音字代替：ㄅ 唸「玻」（ㄅㄛ）；
  拼好的注音（ㄇㄠ）也一樣寫 `唸:貓`。聲調符號（ˊˇˋ˙）目前認不得，拼音卡先只放一聲的字

### 數一數

- 數字卡放 emoji，正面會畫出那麼多個東西讓小朋友點著數
- 會說「apples」「十一顆蘋果」的 emoji 列在 `src/utils/cards.ts` 的 `COUNT_NOUNS`（英文、量詞、中文），
  新的 emoji 要加在那裡才會說對量詞；沒列的一樣可以數，只是會說「Touch them」
